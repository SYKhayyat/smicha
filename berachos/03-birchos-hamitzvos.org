מקורות: ברכות נ"ד—ס"ד; פסחים ז'; רמב"ם הלכות ברכות פ"ו, פי"א; טור ובית
יוסף או"ח סי' רי"ח—רל"ח; שו"ע ורמ"א; מג"א, ט"ז, מ"ב; יביע אומר.

* א. ‡ שלושת סוגי הברכות

| הסוג          | מתי                          | דוגמה              |
|---------------+------------------------------+--------------------|
| ברכות הנהנין  | קודם הנאה                    | המוציא, שהכל       |
| ברכות המצוות  | קודם קיום מצוה               | על נטילת ידים      |
| ברכות השבח    | על ראייה, שמיעה, ומאורע      | שהחיינו, דיין האמת |

* ב. ‡ ברכות המצוות

** א. ‡ "עובר לעשייתן"
כל הברכות מברכים *קודם* עשיית המצוה.
- ‡ הטעם :: שיברך על המצוה בעודה לפניו; ועוד, שיקדש עצמו קודם.

** ‡ היוצאים מן הכלל
1. *טבילת גר* :: מברך אחר הטבילה — שקודם לכן אינו בר חיובא.
2. *טבילת אשה* :: ‡ מחלוקת — עי' [[file:../nidda/05-chatzitzah-tevilah.org][נדה 05]].
3. *הדלקת נר שבת* :: ‡ מחלוקת — עי' [[file:../shabbos/19-neros-kiddush-havdalah.org][שבת 19]].

** ב. ‡ אלו מצוות טעונות ברכה

*** ‡ הכלל
- מצוות שיש בהן *מעשה* — טעונות ברכה.
- מצוות שהן *שב ואל תעשה* — אינן טעונות.
- ‡ מצוות שבין אדם לחברו (צדקה, ביקור חולים) — אינן טעונות.
  - ‡ הטעם :: — ‡ מחלוקת:
    1. שתלויות בקבלת המקבל, ואם לא יקבל — נמצאת ברכה לבטלה.
    2. שהן מצוות שכליות.
    3. שאין להן שיעור וגבול.

*** ‡ מצוות שאין מברכים עליהן
- צדקה, כיבוד אב ואם, השבת אבידה, ביקור חולים, ניחום אבלים.
- ‡ ובזה יש חילוקים ומחלוקות. ⚠

** ג. ‡ נוסח "וצוונו"
- במצוות דאורייתא — פשוט.
- ‡ במצוות דרבנן :: "וצוונו" — מנין?
  - "לא תסור מן הדבר אשר יגידו לך".
  - "שאל אביך ויגדך".

** ד. ‡ מי מוציא את מי
- *ערבות* :: כל ישראל ערבים זה בזה, ולכן מי שכבר יצא — מוציא
  את חברו.
- ‡ *בברכות הנהנין* :: אין ערבות, ואינו מוציא אלא אם כן אוכל עמו.
- ‡ *נשים מוציאות אנשים* :: —
  - במצוה שהן חייבות בה כמותו — כן.
  - במצוה שהן פטורות — ‡ מחלוקת. ⚠

* ג. ‡ שהחיינו

** א. ‡ מתי מברכים
1. *מצוה הבאה מזמן לזמן* — יו"ט, שופר, לולב, נר חנוכה.
2. *פרי חדש* של אותה שנה.
3. *בגד חדש* חשוב.
4. *בשורה טובה* לו לבדו.

** ב. ‡ פרי חדש
- ‡ תנאי :: שיהא *מתחדש משנה לשנה* ויש בו שמחה.
- ‡ *פרי המצוי כל השנה* :: אין מברכים.
- ‡ *בזמן הזה*, שרוב הפירות מצויים תמיד :: — יש מקום להקל, ומכל
  מקום על פרי שניכר בו חידוש — מברכים. ⚠

** ג. ‡ בגד חדש
- ‡ *בגד חשוב* :: מברך "שהחיינו".
- ‡ *ובגד שיש בו שותפות* :: "הטוב והמטיב".
- ‡ *נעליים ובגדי עור* :: — ‡ מחלוקת אם מברכים, שיש בהם צער
  בעלי חיים. ⚠

** ד. ‡ להלכה
- אשכנזים :: המ"ב מרחיב במקצת.
- ספרדים :: *סב"ל* — והגר"ע יוסף צמצם מאוד את ברכת שהחיינו, ואינו
  מברך אלא בדבר ברור. ⚠
- ⟐ וזו נפקא מינה מעשית שכיחה.

* ד. ‡ הטוב והמטיב ודיין האמת

** 1. הטוב והמטיב
על טובה שיש בה *הנאה לו ולאחרים*.

** 2. דיין האמת
על שמועה רעה, ועל מיתת קרוב.
- ‡ *בשם ומלכות* :: כן.

** ‡ היסוד
"חייב אדם לברך על הרעה כשם שמברך על הטובה" — וזהו יסוד בעבודת ה',
שהכל לטובה.

* ה. ‡ ברכות הראייה והשמיעה

| המאורע                    | הברכה                         |
|---------------------------+-------------------------------|
| ברקים, הרים, ימים         | עושה מעשה בראשית              |
| רעמים                     | שכחו וגבורתו מלא עולם         |
| קשת                       | זוכר הברית                    |
| אילנות בניסן              | ברכת האילנות                  |
| חכם בתורה                 | שחלק מחכמתו ליראיו            |
| חכם באומות                | שנתן מחכמתו לבשר ודם          |
| מלך                       | שנתן מכבודו לבשר ודם          |
| בריות משונות              | משנה הבריות                   |

** ‡ הכלל בברכות אלו
- ‡ *שלושים יום* :: אין מברכים על אותו דבר בתוך שלושים יום.
- ‡ *סב"ל* :: ובכל הברכות הללו — הספרדים ממעטים יותר, וכן פסק
  הגר"ע יוסף. ⚠

* ו. ‡ ברכת הגומל

** א. ‡ החיוב
ארבעה צריכים להודות (ברכות נ"ד ע"ב):
1. *יורדי הים*.
2. *הולכי מדבריות*.
3. *חולה שנתרפא*.
4. *חבוש בבית האסורים שיצא*.

** ב. ‡ המחלוקת בהיקף

*** ‡ שתי שיטות
- דעה א' :: *דוקא ארבעה אלו* — שכך נמנו.
- דעה ב' :: *כל הניצול מסכנה* — וארבעה אלו לדוגמא.

*** להלכה
- אשכנזים :: הרמ"א — ‡ נהגו לברך רק בארבעה אלו; ויש מברכים
  בכל סכנה. ⚠
- ספרדים :: מרן — כל הניצול מסכנה מברך. וכן הגר"ע יוסף. ⚠
- ⟐ נפקא מינה :: נסיעה במטוס, תאונת דרכים, ניתוח.

** ג. ‡ נשים
- ‡ מחלוקת אם מברכות בפני עשרה.
- להלכה ::
  - אשכנזים :: ‡ יש נוהגות לברך בפני נשים, או שבעלה מברך.
  - ספרדים :: הגר"ע יוסף — מברכות בפני עשרה. ⚠

** ד. ‡ תנאים
1. *בפני עשרה*, ושנים מהם תלמידי חכמים.
2. ‡ *תוך שלושה ימים* — ולכתחילה; ובדיעבד עד שלושים יום.

* ז. ⟐ הכלל שיש לחזור עליו בכל הקובץ

#+begin_quote
*ספק ברכות להקל.*
#+end_quote

וזהו ההבדל המרכזי בין הקהילות: אצל ספרדים סב"ל הוא כלל כמעט מוחלט,
ומכריע אף נגד פסק מרן. ואצל אשכנזים המ"ב מכריע לפי רוב הפוסקים,
ומברך במקומות שהספרדים אינם מברכים.

*ולכן:* בכל שאלת ברכה, צריך לדעת קודם *לאיזו קהילה* השואל שייך.
