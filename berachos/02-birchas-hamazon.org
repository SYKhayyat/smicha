#+TITLE: ברכות — ברכה אחרונה, ברכת המזון, וזימון

מקורות: ברכות מ"ד—נ"ג; רמב"ם הלכות ברכות פ"א—פ"ה; טור ובית יוסף או"ח
סי' קפ"ג—ר"ח; שו"ע ורמ"א; מג"א, ט"ז, מ"ב; יביע אומר, ילקוט יוסף.

* א. ‡ ברכת המזון — תוקפה

** המקור
"ואכלת ושבעת וברכת את ה' אלהיך" (דברים ח') — *מדאורייתא*.

** ‡ שיעור החיוב מדאורייתא
- ‡ מחלוקת :: "ושבעת" — האם צריך *שביעה* ממש.
  - דעה א' :: מדאורייתא חייב רק כשאכל ושבע; ובכזית — מדרבנן.
  - דעה ב' :: כזית מדאורייתא.
- להלכה :: כזית — ואם ספק, ‡ סב"ל בכזית ומברך בשביעה. ⚠

** ‡ ארבע הברכות
1. *הזן* — משה רבנו, על המן.
2. *ברכת הארץ* — יהושע, על הארץ.
3. *בונה ירושלים* — דוד ושלמה.
4. *הטוב והמטיב* — ביבנה, על הרוגי ביתר.
- ‡ ולכן :: שלוש הראשונות מדאורייתא, והרביעית מדרבנן.

** ⟐ נפקא מינות
1. *ספק אם בירך* — חוזר, שהוא ספק דאורייתא.
   - ‡ ובספק אם אכל כזית :: אינו חוזר.
2. *דילג ברכה* — אם דילג אחת מן השלוש, חוזר.
3. *הטוב והמטיב* — דילג, אינו חוזר.

* ב. ‡ שלוש ברכות אחרונות

| הברכה                | על מה                                  |
|----------------------+----------------------------------------|
| ברכת המזון           | פת מחמשת המינים                        |
| מעין שלוש            | מזונות, יין, שבעת המינים               |
| בורא נפשות           | כל שאר הדברים                          |

** ‡ מעין שלוש
- ‡ החתימה משתנה לפי המין: "על המחיה", "על הגפן", "על הפירות".
- ‡ *אכל כמה מינים* :: כוללן בברכה אחת, ובסדר הראוי.

** ‡ ספק בברכה אחרונה
- ברכת המזון — ספק דאורייתא, חוזר.
- מעין שלוש ובורא נפשות — דרבנן, אינו חוזר.

* ג. ‡ קביעות סעודה על מזונות

** ‡ הדין
פת הבאה בכיסנין — ברכתה מזונות. ואם *קבע עליה סעודה* — ברכתה
המוציא וברכת המזון.

** ‡ מהו שיעור הקביעות — מחלוקת גדולה

*** ‡ שלוש שיטות
1. *כשיעור שאחרים קובעים עליו* — כשלוש או ארבע ביצים. ⚠
2. *כשיעור שביעה* — שיהא שבע ממנו.
3. *לפי דעתו* — שיקבע עצמו לסעודה.

*** להלכה
- ‡ *פחות מכביצה* :: מזונות בודאי.
- ‡ *בין כביצה לשיעור קביעות* :: מזונות.
- ‡ *שיעור קביעות* (‡ כארבע ביצים, ובמידות זמננו כ־230 גרם) ⚠ ::
  נוטל ידיו ומברך המוציא.
- ‡ *ובספק* :: —
  - אשכנזים :: המ"ב מכריע לפי השיעור.
  - ספרדים :: הגר"ע יוסף — סב"ל; ואם אינו ברור, מברך מזונות
    ועל המחיה, ובשיעור גדול נוטל ומברך המוציא. ⚠

** ‡ "פת הבאה בכיסנין" — שלוש הגדרות
1. עיסה שנילושה ב*מי פירות* (דבש, שמן, יין) ולא במים.
2. עיסה *ממולאה*.
3. עיסה *יבשה וקשה* שנוגסים אותה.
- ‡ ולהלכה :: חוששים לכולן, וכל אחת עושה אותה כיסנין. ⚠

* ד. ‡ דברים הבאים מחמת הסעודה

** הכלל
כל שנאכל *בתוך הסעודה* ומחמת הסעודה — נפטר בהמוציא.

** ‡ שלוש דרגות

| הדבר                              | הדין                       |
|-----------------------------------+----------------------------|
| דברים הבאים מחמת הסעודה (מזון)    | נפטרים בהמוציא             |
| דברים שאינם מחמת הסעודה (פירות)   | ‡ מחלוקת — טעונים ברכה     |
| משקין                             | ‡ טעונים ברכה              |

** ‡ המחלוקת בפירות בתוך הסעודה
- דעה א' :: נפטרים, שהכל טפל לפת.
- דעה ב' :: טעונים ברכה, שאינם מחמת הסעודה.
- להלכה :: טעונים ברכה ראשונה, ואינם טעונים ברכה אחרונה
  (שנפטרים בברכת המזון). ⚠

** ‡ יין בתוך הסעודה
- ‡ מברך "הגפן" עליו, שהוא חשוב.
- ‡ ואם בירך על כוס קידוש — פוטר את היין שבסעודה.

* ה. ‡ זימון

** א. ‡ החיוב
שלושה שאכלו כאחד — חייבים לזמן.
- ‡ תוקפו :: מדרבנן.

** ב. ‡ תנאי הזימון
1. *שלושה* שאכלו *פת*.
2. שאכלו *כאחד* — בקביעות אחת.
3. ‡ *שיעור* :: כזית לכל אחד. ‡ ויש מצריכים כביצה. ⚠

** ג. ‡ עשרה — בשם
בעשרה מוסיפים "אלהינו".

** ד. ‡ נשים
- ‡ *נשים חייבות בברכת המזון* :: — ‡ מחלוקת אם מדאורייתא (שאין
  להן חלק בארץ) או מדרבנן. ולהלכה חייבות. ⚠
- ‡ *זימון נשים* :: —
  - שלוש נשים שאכלו — ‡ מחלוקת אם חייבות או רשות.
  - להלכה ::
    - אשכנזים :: הרמ"א — רשות, ונהגו שלא לזמן.
    - ספרדים :: הגר"ע יוסף — ‡ חייבות, ויש להנהיגן לזמן. ⚠
- *נשים עם אנשים* :: מצטרפות לשמוע, ואינן מצטרפות למנין.

** ה. ‡ פרטים
1. *נחלקו* :: שלושה שאכלו — אין רשאים לחלק.
2. *יצא אחד* :: — ‡ אם יצא אחד קודם, מזמנים בשנים ואחד? — לא.
3. *"בריך רחמנא"* :: נוסח קצר בשעת הדחק.
4. ‡ *כוס של ברכה* :: —
   - אשכנזים :: נהגו בכוס בזימון של עשרה, ולא תמיד.
   - ספרדים :: מקפידים יותר על כוס בכל זימון. ⚠

* ו. ‡ נטילת ידים לסעודה

** א. ‡ יסודה
- ‡ מחלוקת :: אם משום *טהרה* (סרך תרומה) או משום *נקיות*.
- ‡ תוקפה :: מדרבנן.

** ב. תנאיה
1. *כלי*.
2. *כח גברא* — שיבואו המים בכחו.
3. *רביעית* לכל הפחות. ⚠
4. *שלא יהא חוצץ*.
5. *מים כשרים* — שלא נשתנו ולא נעשתה בהם מלאכה.

** ג. ‡ הברכה
"על נטילת ידים" — קודם הניגוב, ולאחר הנטילה. ⚠

** ד. ‡ שיעור הפת המחייב נטילה
- ‡ *כביצה* :: נוטל ומברך.
- ‡ *כזית עד כביצה* :: נוטל בלא ברכה.
- ‡ *פחות מכזית* :: אינו נוטל.
- ‡ ובזה נחלקו, וסב"ל. ⚠

** ה. ‡ דבר שטיבולו במשקה
- הטובל מאכל במשקה — נוטל ידיו בלא ברכה.
- ‡ ובזמן הזה :: —
  - אשכנזים :: המ"ב מצריך; ורבים אינם נזהרים אלא בליל הסדר.
  - ספרדים :: מקפידים יותר. ⚠

* ז. ⟐ סיכום — סדר הבירור בברכה אחרונה

1. האם אכל *שיעור* — כזית או רביעית?
2. האם אכל בתוך *כדי אכילת פרס*?
3. מה ה*מין* — פת, מזונות, שבעת המינים, אחר?
4. האם היה *הפסק או היסח דעת*?
5. האם יש *זימון*?
6. אם יש *ספק* — סב"ל, חוץ מברכת המזון בודאי כזית.
