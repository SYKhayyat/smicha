מקורות: שו"ע או"ח ס"ב—ל"ו (נבדקו מהטקסט) ויו"ד רע"א,
רע"ד, רע"ח (נבדקו מהטקסט); היסודות המעשיים —
[[file:06-mezuzah-sifrei-kodesh.org][יו"ד 06]].

* א. ‡ הקלף ועיבודו (או"ח ל"ב)

** שלשת החומרים
| שם            | הגדרה                          |
|----------------+---------------------------------|
| **גויל**      | העור **שלא נחלק** — צד השער    |
| **קלף**       | החלק ה**חיצון** אחר החלוקה     |
| **דוכסוסטוס** | החלק הפנימי הדבוק לבשר         |

- הלכה למשה מסיני :: תפילין **על הקלף** — "וכותבין על הקלף
  במקום בשר"; שינה :: פסול. *וקלפים שלנו שאין חולקין* ::
  דינם קלף — וכותבין לצד בשר.
- ספר תורה :: על **גויל**; ועל קלף — כשר בצד פנימי; ***והרמ"א:
  "קלפים שלנו יותר מובחרים... ואין כותבין עכשיו על הגויל."***

** לשמו
- "**צריך שיהא מעובד לשמו** — טוב להוציא בשפתיו בתחלת העבוד"
  (לשם תפילין / ס"ת); עיבדו לשם מזוזה :: פסול לתפילין.
- עיבדו **עכו"ם** :: לרמב"ם פסול; להרא"ש כשר אם ישראל עומד
  על גבו וסייעו — *וכן נוהגין* (רמ"א).

** מיני העורות
- בהמה חיה ועוף **טהורים** — ואפילו מנבלות וטריפות שלהם;
  *לא* מטמאים; **לא מעור דג אפילו טהור** — "משום דנפיש
  זוהמיה."
- הקלף שלם :: שלא תהא אות **נראית חלוקה לשתים** ע"י נקב.

* ב. הדיו (או"ח ל"ב, יו"ד רע"א)

- **שחור**; ולכתחילה — מעשן עצים/שמנים שרוי במי עפצים.
- אות א' בצבעונים או ב**זהב** :: **פסולין**.
- זרק אפרות זהב על אות :: מעביר הזהב וכשר; *על אות מאזכרה*
  :: אין תקנה — "משום דהוי **כמוחק את השם**."

* ג. ‡ כתיבה לשמה

- תחלת הכתיבה :: "**אני כותב לשם קדושת תפילין**"; ובכל
  **אזכרה** :: לשם קדושת השם (וי"א דסגי במחשבה אחר
  ההצהרה).
- ***ובספר תורה*** (יו"ד רע"ד): "צריך שיהא לפניו **ספר אחר
  שיעתיק ממנו** — שאסור לכתוב אות אחת שלא מן הכתב, וצריך
  **שיקרא כל תיבה בפיו** קודם שיכתבנה."

* ד. ‡ חוק תוכות — גבול התיקון

| מקרה                              | התקנה                                  |
|------------------------------------+-----------------------------------------|
| טפת דיו נפלה באות                 | **אין לגרור** — "דבעינן וכתב ולא וחקק" |
| כתב דל"ת במקום רי"ש               | אין למחוק התג לתקן                     |
| מ"ם פתוחה נסתמה                   | גורר **כל החרטום** וכותב מחדש          |
| רגל ה"א/קו"ף נגעה בגג             | גורר הרגל וכותבו                       |
| אל"ף נגעה רגלה בגגה               | **אין תקנה בגרירה** — גורר הפסול כולו |

⟐ הכלל הפנימי: *מה שנכתב כתיקון ואח"כ נפגם — יש תיקון;
מה שנעשה כך מתחלת כתיבתו — חוק תוכות.* והכשר התינוק
("שאינו לא חכם ולא טיפש") — רק בנפסק אחר כתיבה כשרה.

* ה. צורת האותיות והתגין (או"ח ל"ו)

- "**שלא תשתנה צורת שום אחת... ולא תדמה לאחרת**" — ומ"מ
  "*אם שינה בצורת הכתב — אינו פסול*" (כל זמן שהצורה
  מכוונת).
- **גולם אחד**: נקודת האל"ף כיו"ד; יו"די השי"ן, עי"ן, אחורי
  צד"י — **נוגעים באות**; *בה"א וקו"ף* — **אין ליגע הרגל
  בגג**.
- תגין :: "**שעטנ"ז ג"ץ**" — חובה לכתחילה; והסופרים נהגו
  לתייג אחרות; *ואם לא תייג — אפילו שעטנ"ז ג"ץ — לא פסל.*

* ו. מרחקים ושרטוט

- כל אות **מוקפת גויל**; בין אות לאות :: כחוט השערה;
  בין תיבה לתיבה :: **כמלא אות קטנה**; הרחקה/הקרבה יתרה ::
  פסול.
- ספר תורה :: **חייב שרטוט** — בלאו פסול; ולא בעופרת;
  *ולתפילין* :: השטה העליונה בעלמא — והרמ"א: נוהגין לשרטט
  הכל.

* ז. ניקוד ופיסוק (יו"ד רע"ד)

- "**ספר המנוקד פסול — ואפילו הסירו ממנו הניקוד**; וכן ספר
  שיש בו פיסוק פסוקים **בדיו**" — ואויר בין הפסוקים :: כשר.

* ח. תפירת ספר תורה (יו"ד רע"ח)

- תופרין **בגידי בהמה/חיה טהורים**; מראש היריעה ועד סופה —
  חוץ ממעט בראש ובסוף; מבחוץ.
- **עצי חיים** :: בראש ובסוף, ובין העמוד לדף — **שתי
  אצבעות**.
- נקרע רוב התפירה ונשארו ה'-ו' תפירות של קיימא :: כשר;
  *יריעה א' שאינה תפורה — אין קורין בו.*

* ט. ⟐ מעבר לקודקס

כתב בית יוסף נגד כתב האר"י, ופרטי צורות האותיות המדויקות —
**מנהגים של כתבים** שאינם כאן בטקסט; לסופר מעשי — ספרי
הסופרים ופוסקי הזמן ⚠.

* י. ⟐ סדר הבירור

1. החומר? → קלפים שלנו לצד בשר; מעובד לשמו.
2. הדיו? → שחור; זהב/צבע — פסול; וזהב על מאזכרה — אין תקנה.
3. לשמה? → הצהרה בפה; ס"ת — מעתיק וקורא בפיו.
4. אות פגומה? → חוק תוכות או תיקון — לפי הטבלה.
5. תגין? → שעטנ"ז ג"ץ לכתחילה; העדרן — אינו פוסל.
6. מרווחים, שרטוט, ניקוד, תפירה? → כס"ו–ח.
