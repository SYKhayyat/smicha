* א. ‡ הגדרות היסוד (יו"ד קל"ט)

** ארבעה גדרים
| גדר       | של עכו"ם            | של ישראל                  |
|-----------+----------------------+----------------------------|
| **אליל** | אסור **מיד**        | עד **שתיעבד**             |
| **תשמיש** | עד שישתמשו          | עד שישתמשו                |
| **נוי**   | כתשמיש              | כתשמיש                    |
| **תקרובת** | משהביאו לפניה      | משעשה ממנו תקרובת         |

‡ הרמ"א :: "*ישראל שזקף לבנה והשתחוה לה עובד כוכבים — נאסרה*."

** ביטול (ס"ב)
- של ישראל :: **אין לה ביטול**.
- של עכו"ם :: האליל, תשמישיה ונויה — **יש להם ביטול**;
  *ותקרובת אין לה ביטול לעולם*.

* ב. ‡ נוי ותקרובת — הגדרות הפועלות

- **נוי** :: מדליק לפניה נרות, שטח לפניה בגדים וכלים נאים.
- **תקרובת** :: כל שכיוצא בו קרב על גבי מזבח (בשר שמנים, סלתות,
  מים ומלח) — הניחו לשם תקרובת: אסור מיד.
- ⟐ דבר שאין מקריבין ממנו בפנים :: אינו נאסר אלא אם עשה
  **כעין זביחה או כעין זריקה המשתברת**, ודרך עבודתה באותו דבר.
- ⟐ *החידוש הרמב"מי* :: שעבדה בקשקוש מקלו — **חייב ולא נאסר**
  (החיוב תלוי בעבודה, האיסור בתקרובת); שבר מקל לפניה ואין
  עובדים אותה כך — לא חייב ולא נאסר. שחט לפניה **חגב** — נאסר
  אף שאין דרך לעובדה בחגב כלל.
- מחיצה :: מה שמצא **בפנים** — אסור (אפילו מים ומלח); חוץ
  מהמחיצה — דרך כבוד: נוי, ואם לאו: מותר.
- **פעור ומרקוליס** :: כל מה שמצא עמהם — אפילו דרך בזיון — אסור.
- מעות וכסות בראשה :: דרך כבוד — אסורים; דרך בזיון (כיס על
  צוארו, בגד מקופל, כלי כפוי על ראשו) — מותרים.

** קנים ושעוה, בגדי כהנים
- נרות שעוה לפניה :: נויה — אסורים; **משכנם או מכרן לישראל ::
  מותרים — כיון שכיבן לצורך עצמו זהו ביטולן**.
- חתיכות שעוה לפניה :: מותרות — לא נויה ולא תקרובת.
- מלבושי כהניהם להיכנס :: נוי **שלהם** ולא של אלילים — ואפילו
  ביטול אינם צריכים; וי"א מצריכים. מה שלובשין **לעבודת האליל
  עצמה** :: נוי — צריך ביטול.
- כלים בידו והמחתה :: משמשיה — צריכים ביטול; מכרם/משכנם ::
  ביטול — וי"א אינו ביטולם.

** ולמצוה?
"*נרות ושעוה של אלילים אסורים לנר מצוה דשבת ודחנוכה ודבית
הכנסת*" — משום **דמאיסי**. וכן תכשיטי כהניהם — לא יתקן מהם
טליתות ושום דבר מצוה.

** ספריהם
- לא יכתוב ישראל על ספריהם אלא אם מחקן שלא יהיה רישומן ניכר;
  וי"א אפילו הכי לא — "**דאין קטיגור נעשה סניגור**".
- מכירת ספרים :: יש מתיר; והרמ"א: אסור למכור **ספרים השייכים
  לזמר בהם לעבודת כוכבים**; והמחמיר תבא עליו ברכה — אפילו
  קלפים ודיו; ואין לקשור ספריהם חוץ מספרי הדיינים והסופרים;
  **ואם חשש משום איבה — כל מה שיכול להשמט ישמט**.

* ג. ‡ איסור הנאה (יו"ד קמ"ב)

- האליל וכל הנאות הבאות ממנה אסורות; **אם שרפה :: אסור בגחלתה
  ואפרה — אבל מותר ליהנות משלהבתה**.
- סכין ששחט בה :: מותר — **מפני שהוא מקלקל**; אם הבהמה מסוכנת
  (מתקן!) — אסורה; אסור לחתוך בה בשר — מתקן; ואם חתך דרך
  הפסד — מותר.
- עצי איסור בתנור :: **יוצן ויחם בעצי היתר**; ואם לא צננו ואפה
  בו (בעוד אבוקה כנגדו) :: אסור — "**יש שבח עצי איסור בפת**";
  נתערבה באחרות :: דמי אותה ככר לים המלוח. ופת על **גחלים** ::
  מותרת — "כיון שנעשו גחלים הלך איסורן".
- קערות שבשלן בעצי אלילים :: אסורות בהנאה — דבר אסור בהנאה
  עשאן חדשים; קדרה משני המינים :: התבשיל אסור.
- **גורם מותר** :: שדה שזבלה בזבל אלילים — מותר לזרוע; פרה
  שפטמה בכרשיני אלילים — תיאכל.
- **צל** :: אשרה — אסור לישב בצלה ולעבור תחתיה אם יש דרך אחרת
  כמוה; בית אלילים :: תוכו ונגד פתחו ד' אמות אסור, צל שלאחריו
  מותר; ואפילו תוכו — אם **גוזל הרבים** שקדם הדרך.
- אפרוחים באשרה :: שאינם צריכים לאמן — מותרים; ביצים ושצריכים
  אמן — אסורים; הקן — מותר.
- מרחץ עם אלילים :: מותר לרחוץ — נעשה לשם נוי; **ובזמן שמבזים
  אותה (על הביב) אין בה מנהג אלהות**; ואם דרך עבודתה בכך — אסור.
- "*אסור לשמוע כלי שיר של אלילים או להסתכל בנוי אלילים, כיון
  שנהנה בראייה*" — **ודבר שאין מתכוין — מותר** (רמ"א).

* ד. ‡ מה מותר מעצמו (יו"ד קמ"ה)

** הכלל המכריע
"כל שאין בו **תפיסת יד אדם** ולא עשהו אדם — אע"פ שנעבד,
מותר בהנאה": המשתחוה להר — לא נאסר; נהרות ומעיינות של רבים;
אילנות שלא נטען לשם אלילים. ⟐ *אבל*: כל השריגים והעלים
והפירות שיוציא **כל זמן שהוא נעבד** — אסורים; וציפויו אסור.

** הטבלה
| עצם                          | דין                                  |
|------------------------------+---------------------------------------|
| הר, נהר, מעיין              | מותר (אין תפיסת יד)                   |
| בית שבנאו מתחילה לעבדה      | אסור; הוציא האליל — מותר (אם לא הוקצה) |
| אבן שחצבה/ציירה לעבדה       | החידוש אסור, השאר מותר                |
| אבן שהועמד עליה             | אסורה **כל זמן** שהיא תחתיו           |
| אילן שנטע מתחילה / הבריך    | השריגים אסורים; גוף מותר              |
| קרקע                         | אינה נאסרת — אלא אם חפר בה בורות      |
| **בעלי חיים**               | **אינן נאסרים** בהשתחוויה כלל         |

⟐ *אבל*: ששחטה **לאלילים** — נאסרה אפילו **סימן אחד** (נבילה!);
ודוקא עכו"ם אוסר דבר שאינו שלו; ישראל אינו אוסר של חבירו —
חוץ ממומר או שהתרו בו. וחליפי חליפין — מותרים, ויש אוסרים.

* ה. ‡ חגי העכו"ם — הדינים המעשיים (יו"ד קמ"ח)

** שלשה ימים קודם חגם
- אסור ליקח מהם ולמכור להם **דבר המתקיים**; דבר שאינו מתקיים
  (ירקות, תבשיל) — מותר.
- אסור להשאיל, לשאול, **להלוותן וללוות מהם** ולפרוע וליפרע
  בשטר או משכון; *מלוה על פה* — נפרעים (**כמציל מידם**); בזמן
  תקיפתם אף בשטר; ומלוה ברבית — אפילו משכון.
- נשא ונתן **ביום חגם** :: אסור בהנאה; בשלשה שלפניו :: מותר.
- חג של ג'-י' ימים :: כולם כיום אחד, **ועמהם הג' שלפניהם**.
‡ ***ובשאר ארצות — אינו אסור אלא יום חגם בלבד*** (ס"ד).

** והגבלות
- אין לשלוח דורון ביום חגם — אלא אם נודע שאינו מודה באלילים;
  ואם שלח לנו :: לא יקבל; ואם חושש לאיבה — מקבל **ויזרקנו
  בפניו לבור כלאחר יד**.
- יום התכנסות להעמיד שר והקרבה וקילוס :: כחגם.
- חג פרטי (יום לידתו וכיו"ב) :: אסור **אותו יום ואותו איש
  בלבד**.
- השמחים בו שלא מפני אמונה :: מותר לשאת ולתת עמהם.
- אין ליכנס לביתו ביום חגו; מצאו בחוץ — מותר, "ואמר לו בשפה
  רפה ובכובד ראש".
- **אין לכפול לו שלום לעולם** — לפיכך טוב להקדים שלום.

** ⟐ הכרעת הרמ"א — והיא המפתח לימינו
"י"א שאין כל דברים אלו אמורים אלא באותו זמן; אבל **בזמן הזה
אינם בקיאים בטיב אלילים — לפיכך מותר לשאת ולתת עמהם ביום
חגם ולהלוותם וכל שאר דברים**."
והרמ"א מוסיף :: משום **איבה** — "אם נכנס לעיר ומצאם שמחים
ביום חגם — ישמח עמהם, דהוי כמחניף להם"; *ומ"מ בעל נפש ירחיק
מלשמוח עמהם אם יכול בלי איבה*; ודורון — עדיף מבערב.

* ו. התרחקות ומראית העין (יו"ד ק"נ)

- מצוה להתרחק מדרך אלילים **ד' אמות**.
- קוץ ברגלו / מעות שפזורים :: לא ישוח ליטלן — אלא ישב, או יפנה
  אחוריו וצדו, ואח"כ יטול.
- מי שפורצות מים לפניה :: לא יניח פיו על פיהם — משום מנשק.
‡ *והרמ"א מכריע בין כבוד לחיים*: "אם יש סכנה בדבר... **מותר
לשתות ואין בזה משום יהרג ואל יעבור**."
- שרים שיש בבגדיהם צורת עבודת כוכבים / צורת חמה לפניהם ::
  לא ישתחוה ולא יסיר כובע — אלא בדרך שאינו נראה, או קודם בואם;
  ויש מקילין — **וטוב להחמיר**.

* ז. ‡ חוקות העכו"ם (יו"ד קע"ח)

** הכלל וחלוקתו
"אין הולכין בחוקות העובדי כוכבים ולא מדמין להם" — אלא יהא
**מובדל** במלבושיו ובשאר מעשיו. *ובמה דברים אמורים?*
1. **דבר שנהגו בו לשם פריצות** (מלבוש אדום של שרים וכדומה).
2. **דבר שנהגו למנהג וחוק ואין טעם בדבר** — דאיכא למיחש
   משום **דרכי האמורי**, ושמץ עבודת כוכבים.
3. *אבל דבר שנהגו לתועלת* — כגון **מלבוש מיוחד לרופא מומחה**
   — מותר; וכן משום כבוד או טעם אחר; ולכן "שורפין על המלכים
   ואין בו משום דרכי האמורי".
4. **הקרוב למלכות** שצריך ללבוש מלבושיהם :: **מותר בכל**.

** וסעיפי הסימן
- אכל והשאיר פתיתין — לא יביא פת שלימה על השלחן.
- עריכת שלחן לילה שלמחרת מילת תינוק :: יש בו משום
  **העורכים לגד שלחן**; לערוך מטה למזל התינוק — יש מתירין.

* ח. ⟐ שאלות שהקודקס אינו פותר

אילו דתות נחשבות עבודה זרה ממש, ומה הוא "שיתוף" לעכו"ם —
**אין בטקסט כאן תשובה**; וכן הגדרת "חוקות" בחברה המודרנית
(מספרים, טכנולוגיה, נימוסים). אלו נבנות על החלוקה של סעיף ז
— *פריצות / חוק חסר-טעם / תועלת וטעם* — **אבל הפסקים
לפוסקים** ⚠.

* ט. ⟐ סדר הבירור

1. מה העצם? → אליל / תשמיש / נוי / תקרובת — ושל מי (עכו"ם:
   מיד; ישראל: עד עבודה).
2. יש ביטול? → לעכו"ם כן (חוץ מתקרובת); לישראל לא.
3. הנאה? → שלהבת מותרת, גחלים אסורים; מקלקל מותר, מתקן אסור;
   גורם מותר.
4. יש תפיסת יד אדם? → הכלל של קמ"ה.
5. חגם? → שלשה ימים + החג (בחו"ל: החג בלבד); מסחר ביום —
   אסור בהנאה; וכל זה — עד הכרעת הרמ"א של "בזמן הזה".
6. מראית עין נגד סכנה? → **סכנה קודמת**.
7. מנהג עכו"ם? → פריצות/חוק-חסר-טעם: אסור; תועלת וטעם: מותר.
