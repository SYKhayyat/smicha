* א. ‡ ארבע התעניות (או"ח תקמ"ט)

- חייבים :: **ט' באב, י"ז בתמוז, ג' בתשרי, י' בטבת**.
‡ למה י"ז ולא ט' בתמוז? "כיון שבשניה הובקעה בי"ז — תקנו
להתענות בי"ז, משום **דחורבן בית שני חמיר לן**."

* ב. ‡ ההבדל בין ט' באב לשאר הצומות (ת"נ)

| דין                    | ג' צומות              | ט' באב            |
|-------------------------+------------------------+--------------------|
| עוברות ומיניקות         | אינן מחויבות           | **מחויבות להשלים** |
| רחיצה/סיכה/סנדל/תשמיש | **מותר**               | אסור (→ תקנ"ד)    |
| הפסק מבעוד יום          | אין צריך               | צריך              |
| חל בשבת                 | נדחה                   | נדחה              |

- אם חלו בערב שבת :: קורין **והיו"ד** בשחרית ומנחה.
- בשבת שלפני הצום :: ש"ץ מכריז "הצום" — חוץ מט"ב ויו"כ;
  ומנהג האשכנזים שלא להכריז כלל.

* ג. ‡ ערב תשעה באב (תקנ"ב)

** הסעודה המפסקת
- אין אוכלין בה **בשר ויין** ולא **שני תבשילין**; וממעטים
  בשתיה; ולא צנון ומליח.
- בשר מלוח שעברו עליו ב' ימים, עופות, דגים, יין מגתו :: נהגו
  לאסור.
- שני תבשילין :: אפילו **מין אחד בשתי קדרות**; ויש להחמיר
  בשני מינים בקדרה א' — אלא א"כ דרכו כך (אפונין).
- מנהג :: עדשים עם ביצים / ביצים קשים — מאכלי אבלים.
- מי שאפשר לו :: **פת חריבה במלח וקיתון של מים**; יושב
  **על גבי קרקע**; *ולא ישבו שלשה — שלא יתחייבו בזימון.*

** הגבלות הזמן
- כל זה — **בסעודה המפסקת אחר חצות** שאין דעתו לאכול אחריה
  קבע.
- מנהג גלילות אשכנז :: סעודה קבועה קודם מנחה, מנחה,
  ואח"כ המפסקת; ומרבים בראשונה "כדי שלא יזיק להם התענית".
- חל ט"ב בא' בשבת (או נדחה) :: אוכל בשר ויין אפילו "כסעודת
  שלמה" — *ומ"מ צריך להפסיק מבעוד יום*.
- **אין אומרים תחנון** במנחה — "משום **דאיקרי מועד**".

* ד. ‡ תשעה באב — חמשת הענויין ותורה (תקנ"ד)

** הענויין
אסור :: **אכילה ושתיה, רחיצה, סיכה, נעילת הסנדל, תשמיש
המטה**.
- רחיצה :: אפילו **להושיט אצבעו** — אסור; טבילה של מצוה ::
  בזמן הזה אין — לא טובלים.
- ידיים מלוכלכות / צרכים :: מרחיץ **לפי הצורך**; נטילת
  שחרית :: **עד סוף האצבעות**; ומעביר הלחות על עיניו.
- ההולך להקביל פני רבו / אביו / לצרכי מצוה :: **עובר במים
  עד צוארו** — ואינו חושש; וכן בחזרה; *השומר פירותיו — בחזרה
  אסור.*
- מפה רטובה שנגבת :: מקנח בה פנים ורגלים — אף לתענוג ("כיון
  שהיא נגובה").
- סיכה :: אסורה רק **של תענוג**; חטטין בראשו — סך כדרכו.
- סנדל :: **דוקא של עור**; של בגד/עץ/שעם — מותר.
- ואבל ומנודה בדרך :: נועלין — עד העיר; *ובמקום שדרים בין
  עכו"ם — לא יחלוץ אלא ברחוב היהודים.*

** תלמוד תורה
- אסור לקרות תורה נביאים כתובים, משנה, מדרש, גמ' — "**פקודי
  ה' ישרים משמחי לב**"; ותינוקות של בית רבן **בטלים**.
- מותר :: **איוב, והדברים הרעים שבירמיה** (ודלג פסוקי נחמה),
  **איכה ופירושיה, ופרק אלו מגלחין**, סדר היום, פרשת
  הקרבנות, משנת איזהו מקומן.
- יש אוסר ללמוד ע"י הרהור.

** מי חייב
- **עוברות ומיניקות מתענות ומשלימות** — כיום כפור; ובג'
  צומות — פטורות (וראוי שלא להתענג).
- חולה :: "**במקום חולי לא גזרו רבנן**" — מאכילין מיד, בלא
  אומד; והרמ"א: נוהגין להתענות כל זמן שאין צער גדול שיש
  לחוש לסכנה.

** שלום, שוק, ומלאכה
- **אין שאלת שלום**; ומי שנתן לנו — משיבים "בשפה רפה
  ובכובד ראש".
- לא לטייל בשוק — שלא יבא לידי שחוק.
- מלאכה :: **מנהג המקום מכריע**; ת"ח בטלים בכל מקום; ע"י
  עכו"ם — מותר אפילו בביתו; *ולא נהגו באיסור אלא עד חצות*
  (רמ"א); מלאכת דבר האבד — מותר.
- ⟐ "*כל העושה מלאכה בתשעה באב — אינו רואה סימן ברכה
  מאותה מלאכה.*"
⟐ "***כל האוכל ושותה בתשעה באב — אינו רואה בשמחת ירושלים;
וכל המתאבל על ירושלים — זוכה ורואה בשמחתה.***"

* ה. ⟐ סדר הבירור

1. איזה צום? → ג' אחרונים: הקלות שבת"נ; ט"ב: החומרות.
2. עוברת/חולה? → בט"ב כיו"כ; בשאר — פטור.
3. ערב ט"ב → סעודה מפסקת: בשר/יין/שני תבשילין — לא; ואחר
   חצות.
4. נטילה, סיכה, סנדל, רחיצה לצורך? → על פי ס"ד.
5. ת"ת? → איכה ואיוב וקינות בלבד.
6. ותמיד: התענית תקנה — ולא גזרו רבנן במקום חולי.
