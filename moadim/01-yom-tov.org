#+TITLE: יום טוב — אוכל נפש, מתוך, מוקצה, ועירוב תבשילין
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות: מסכת ביצה; רמב"ם הלכות שביתת יום טוב; טור ובית יוסף או"ח סי' תצ"ה—תקכ"ט;
שו"ע ורמ"א; מג"א, ט"ז, מ"ב, ערוה"ש; כף החיים, יביע אומר, ילקוט יוסף.

* א. ‡ יסוד ההיתר — "אך אשר יאכל לכל נפש"

** המקור
"כל מלאכה לא יעשה בהם, אך אשר יאכל לכל נפש הוא לבדו יעשה לכם"
(שמות י"ב).

** ‡ מה הותר
*מלאכת אוכל נפש* — ולא כל המלאכות.

** ‡ המלאכות שלא הותרו אף לאוכל נפש
- *קוצר, טוחן, בורר, מרקד, צד, דש* — שהיה אפשר לעשותן מערב יום טוב,
  ואינן נפסדות.
- ‡ ולכן :: הכלל — *"מכשירי אוכל נפש שאפשר לעשותן מערב יום טוב —
  אין עושין ביום טוב"*.

** ‡ שני הכללים המגבילים

*** 1. "אפשר לעשותו מערב יום טוב"
כל מה שאפשר היה להכין מבעוד יום, ואינו נפסד — אסור.

*** 2. "אין עושין ביו"ט מלאכה שאין בה צורך היום"
צריך שיהא לצורך *אותו יום*.

* ב. ‡ "מתוך שהותרה לצורך, הותרה שלא לצורך"

** הכלל
מלאכות שהותרו לאוכל נפש — *מתוך* שהותרו לצורך אכילה, הותרו אף
לצרכים אחרים.

** ‡ אלו הן
*הבערה, הוצאה, בישול, שחיטה, אפייה* ⚠ — ומכל מקום צריך *צורך
היום* קצת.

** ‡ שלוש שיטות בגדר "מתוך"
- שיטה א' :: הותר לגמרי, אף בלא שום צורך.
- שיטה ב' :: צריך *צורך היום* כלשהו — הנאה או שמחה.
- שיטה ג' :: צריך *צורך שווה לכל נפש*.

** להלכה
צריך *צורך היום*, ולפחות *צורך קצת*. (שו"ע או"ח סי' תקי"ח ⚠)

** ⟐ נפקא מינות
1. *הוצאה ביו"ט* :: מותרת אף שלא לצורך אוכל — כגון מפתח, סידור,
   וילד. ובלבד שיהא בו צורך היום.
   - ‡ ומכל מקום :: אין להוציא דבר שאין בו צורך כלל, כגון אבנים.
2. *הבערה* :: מותרת מאש קיימת. ואסורה *הולדת אש חדשה*.
3. *טלטול* :: מוקצה — עי' להלן.

* ג. ‡ הבערה ביום טוב

** ‡ הכלל
- *העברה מאש לאש* :: מותרת.
- *הולדת אש חדשה* :: אסורה — "*אין מוציאין את האור*" (ביצה ל"ג ע"א).

** ‡ הטעם
מוליד — יצירת דבר שלא היה. ואף שהבערה הותרה, הולדה לא הותרה,
שאינה "אוכל נפש" אלא בריאה חדשה.

** ⟐ נפקא מינות
1. *גפרור* :: אסור להדליק.
2. *נר מנר* :: מותר.
3. *חשמל* :: אסור — עי' [[file:../shabbos/20-chashmal.org][שבת 20]].
4. *כיבוי* :: אסור ביו"ט כבשבת.
   - ‡ *כיבוי לצורך אוכל נפש* :: — ‡ מחלוקת; ולהלכה אסור,
     ומותר ב*גרמא* ובהנמכה לצורך התבשיל. ⚠
   - ‡ *הנמכת להבה* :: — ‡ מחלוקת גדולה:
     - יש מתירים כשהוא לצורך התבשיל.
     - ויש אוסרים.
     - להלכה :: אשכנזים — יש מקילים לצורך; ספרדים — הגר"ע יוסף
       הקל להנמיך לצורך התבשיל. ⚠

* ד. ‡ מוקצה ביום טוב

** ‡ הכלל
*"יום טוב חמור משבת לענין מוקצה"* — ביצה ב' ע"ב.

** ‡ הטעם
- שיטה א' :: יו"ט קל בעיני בני אדם, ולכן החמירו בו כדי שלא יזלזלו.
- שיטה ב' :: הכנה — ביו"ט חייבים בהכנה מבעוד יום.

** ⟐ נפקא מינות
1. *נולד* :: אסור ביו"ט אף שמותר בשבת (לר' שמעון).
   - ⟐ ביצה שנולדה ביו"ט — אסורה.
2. *פירות שנשרו* :: אסורים.
3. *אפר* :: אסור.

* ה. ‡ עירוב תבשילין

** א. ‡ הצורך
יום טוב שחל בערב שבת — אין מבשלים מיו"ט לשבת, ש*אין יום טוב מכין
לשבת*.

** ב. ‡ יסוד ההיתר — שתי שיטות

*** 1. "כדי שיברור מנה יפה"
זכר וסימן — שיזכור להניח מזון לשבת ולא יאכל הכל ביו"ט.

*** 2. "כדי שיאמרו — אין אופין מיו"ט לשבת"
היכר, שלא יבואו לומר שאופין מיו"ט לחול.

*** ‡ נפקא מינה
האם העירוב הוא *מתיר* גמור, או *היכר* בעלמא. ⟐ ולענין מי ששכח.

** ג. ‡ אופנו
- *פת ותבשיל* — מניח מערב יום טוב.
- ‡ שיעורם :: כזית תבשיל, וכביצה פת. ⚠
- מברך "על מצות עירוב", ואומר את הנוסח.

** ד. ‡ מי שלא הניח
1. *סומך על עירוב הרב* — שהרב מזכה לכל בני העיר.
   - ‡ ובתנאי :: שלא היה יכול להניח, או ששכח. ומי שהזיד — אינו סומך.
2. *שכח לגמרי* :: יש עצות — לתת מזונותיו לאחר שהניח, או לבשל לצורך
   יו"ט ולהותיר.

** ה. ‡ מה מתירים בו
- *לבשל ולאפות* לשבת.
- *להדליק נרות* לשבת.
- ‡ ובלבד שיגמור *מבעוד יום* — קודם השקיעה.

* ו. ‡ יום טוב שני של גלויות

** א. ‡ מקורו
תקנה מפני *ספק היום*, ובזמן הזה *"מנהג אבותינו בידינו"* — ואף שיודעים
את הלוח.

** ב. ⟐ נפקא מינות
1. *בני ארץ ישראל בחו"ל* :: — ‡ מחלוקת גדולה:
   - יש אומרים שנוהגים כבני המקום שהוא בו.
   - ויש אומרים שנוהגים כמקומם, בצנעה.
   - להלכה :: הדעה הרווחת — נוהג יום אחד בצנעה, ומתפלל של חול
     ביחידות. ⚠
2. *בני חו"ל בארץ ישראל* :: — ‡ מחלוקת אם עושים יום אחד או שנים.
   - להלכה :: הבא על דעת לחזור — עושה שני ימים. ⚠
3. *מלאכה ביו"ט שני* :: אסורה כראשון.
4. ‡ *חולה ביו"ט שני* :: יש קולא — שהוא דרבנן.

* ז. ‡ שמחת יום טוב

** א. החיוב
"ושמחת בחגך" — ‡ מדאורייתא.

** ב. ‡ במה
- *בזמן המקדש* :: בשלמי שמחה.
- *בזמן הזה* :: ביין, בבשר, ובבגדים.
- ‡ *נשים* :: בבגדים ובתכשיטים.
- *קטנים* :: בממתקים.

** ג. ‡ חצי לה' וחצי לכם
מחלוקת ר' אליעזר ור' יהושע, ולהלכה — חולקים.
