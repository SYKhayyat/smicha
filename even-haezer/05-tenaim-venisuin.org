מקורות: שו"ע אה"ע סי' מ"ב, נ', נ"א, נ"ה—נ"ו, נ"ח,
ס"א—ס"ב (נבדקו מהטקסט); והיסודות — [[file:01-ishus-kiddushin.org][קובץ 01]];

* א. ‡ רצון האשה והעדים (מ"ב)

** רצון
- "**אין האשה מתקדשת אלא לרצונה**"; מקדשה בעל כרחה — אינה
  מקודשת. *אבל* איש שאנסוהו עד שקידש :: י"א מקודשת —
  **והוי ספק**.
- "*ואין הולכין בענין קידושין אחר אומדנות והוכחות*": אמרה
  "קדשני", השליך לחיקה, וניערה בגדיה תוך כדי דיבור :: 
  **מקודשת** — אף אם טוענת שלשחוק התכוונה.

** עדים
- שלא בעדים / בעד אחד :: **אינם קידושין** — אפילו שניהם
  מודים (ומי שמחמיר לפני עד א' — כששניהם מודים).
- קידש בפני עד א' ואח"כ בפני אחר :: אינה מקודשת.
- צריך שיראו **את העדים**; והעדים צריכים **הנתינה ממש לידה**
  — שמיעה בלבד :: אינם קידושין.
- עדות שלא נחקרה בב"ד :: אינה קרויה עדות לקידושין — יכולים
  לחזור בה.

* ב. ‡ חזרת קדושין וסבלונות (נ')

** הכלל הגדול
"המקדש... בין שחזרה בה ובין שחזר הוא, בין שמת — **אין
הקדושין חוזרין לעולם**, אפילו קדשה באלף דינר — הרי הם
**מתנה גמורה**." וחוזרין :: קדושי **טעות**, **ממאנת**,
**תנאי** שלא נתקיים, **ספק**. ⟐ ***ומן הנשואין — הקדושין
חוזרין*** (רמ"א מהמהרי"ל).

** סבלונות
- חוץ מ**מאכל ומשתה** (וי"א: דוקא אם אכל שם) ומדברים מועטים
  שנשתמשו שם — **הכל חוזר**, וגובה בב"ד.
- חזרה **בה** :: משלמת הכל — אפילו המשתה, **בזול** (ששה ::
  משלמת ד').

** שידוכין וקנסות
- המשדך ששלח מתנות ונתבטלו :: יחזיר החתן — "כדרך שחוזרות
  סבלונות."
- קנסות שידוכין בקנין ושבועה :: נפטרין ב**המרה, נשתטות,
  קלקול מעשיו** — והשטר אצל שליש אינו אלא הצהרה.
- ‡ *מבנה האסמכתא*: שטר חוב מנגד + מתנה ע"מ להיכנס לחופה;
  והרמ"א: "כן **המנהג פשוט לגבות קנסות**."

* ג. ‡ מה שנקנה באמירה (נ"א)

- חתן וכלה שפסקו נדוניא **ועמדו וקדשו** :: קנו — בלי קנין;
  והאב שפסק לבנו/בתו בנישואין **ראשונים** :: כן.
- *במה דברים אמורים?* שהדברים **מצויים ברשותם** ("אין אדם
  מקנה דבר שלא בא לעולם").
- אינם כשטר לטרוף ממשועבדים; ואח שפסק לאחותו, או בנישואין
  שניים :: **צריכין קנין מיד הפוסק**.
- הרמ"א :: הנקנים באמירה — כשאר חוב, ומוציאים מן היורשין;
  *ולכן נהגו **לעשות תנאים חדשים קודם הנשואין***; ולעני ::
  חייב משום **נדר**; מתנה מועטת לעשיר — משום **מחוסרי
  אמנה**.
- והחתן משלם **שכר התנאים** אם נכתב שטר אחד.

⟐ *וזהו המקור הקרוב לשטר התנאים שלנו* — תקנת מנהג על יסוד
קניין-אמירה ⚠.

* ד. מעמד הארוסה (נ"ה)

- אסורה לו **מדברי סופרים** בבית אביה; ביאה בבית חמיו ::
  מכת מרדות; ואפילו **ייחוד** אסור — ולכן מברכין שבע ברכות.
- **כניסה לחופה = יחוד והפרשה** :: משיערה בה — קנאה
  ונשואה.
- ⟐ *מחלוקת מהי חופה*: י"א הבאתה לביתו (הר"ן); י"א סודר
  על ראשה; י"א ההינומא; ***והמנהג פשוט עכשיו*** :: יריעה
  על כלונסות, ומקדשים ומברכים תחתיה ברבים.
- כתובה :: כותבין **קודם החופה**; ארוסה שמתה :: אין הכהן
  מטמא לה, ואין ירושה ביניהם — אביה קוברה.

* ה. ‡ זמני הנישואין (נ"ו)

| מצב                          | זמן שנותנין              |
|-------------------------------+---------------------------|
| תבעה בנערות                  | **י"ב חדש** מהתביעה     |
| תבעה בבגרות                  | י"ב חדש מהבגר            |
| עברו י"ב בבגרות ואח"כ נתקדשה | **ל' יום**               |
| הבעולה                       | ל' יום                   |
- ולאיש :: כמו לה — לפרנס עצמו.
- עבר הזמן ולא נשא :: **חייב במזונותיה אף בלא כניסה**; אונס
  (חלה, נדה, יום שא"א להיכנס) :: פטור — *ודוקא שחלה תוך
  הזמן*.

* ו. נדוניא ופרנסת הבת (נ"ח)

- "**צוו חכמים** שיתן אדם מנכסיו מעט לבתו — וזהו הנקרא
  **פרנסה**."
- משיא סתם :: לא יפחות מכסות **אשת עני**; עשיר :: כפי
  עשרו.

* ז. ‡ חופה קונה (ס"א)

- "**כיון שהכניס האיש ארוסתו לחופה — אע"ג שלא נבעלה, הרי
  היא כאשתו לכל דבר**": גובה עיקר ותוספת.
- נדה שנכנסה :: י"א אינה כאשתו כלל; י"א דוקא לתוספת.
- **החולה חולת מות**: אע"פ שכונסה עם המטה תחת החופה —
  "***אינו חופה כלל***... ואין בעלה יורשה" (מתשובת הרא"ש).
- ברכות :: אינן מעכבות; ונהגו לברך תחת החופה; ונהגו
  **שהחתן והכלה מתענין ביום חופתן**.
- וכשר שלא תנשא עד שתטהר — *"ועכשיו המנהג שלא לדקדק...
  ומ"מ טוב להודיע לחתן"* (רמ"א).

* ח. ‡ ברכת חתנים (ס"ב)

- בבית החתן **קודם הנישואין**; **שש ברכות** + יין = ז'.
- שני חתנים :: ברכה אחת לשניהם; וי"א משום **עין הרע** —
  *וכן נוהגין לברך לכל א' בפני עצמו.*
- **אין מברכין אלא בעשרה גדולים בני חורין, וחתן מן המנין.**
- משך הברכה :: אלמון עם אלמנה — יום א'; בחור עם אלמנה /
  אלמון עם בתולה — **ז' ימים**.
- **פנים חדשות** :: מברכין בשבילם ז' ברכות; וי"א שבת וי"ט
  כפנים חדשות.
- יצא לאכול בבית אחר לגמרי :: נעשה בית זה עיקר — ומברכין
  שם.

* ט. ⟐ סדר הבירור

1. התקדשה ברצון ובפני ב'? → ודאי; ספק רצון/עד א'? → לב"ד
   מומחה ⚠.
2. חזרו בהם? → קדושין אינם חוזרים; סבלונות כן (חוץ
   מהמשתה).
3. הפסקים? → אמירה קונה רק בגדרי נ"א — ולכן תנאים וקנין
   סודר.
4. מעמד עכשיו? → ארוסה: ייחוד אסור, אין ירושה; חופה:
   הכל כנשואה.
5. זמן נישואין? → י"ב חדשים/ל' יום; ומזונות משעבר הזמן.
6. ותמיד: כתובה לפני חופה, ועשרה לברכות.
