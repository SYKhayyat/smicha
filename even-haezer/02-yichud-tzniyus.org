#+TITLE: אבן העזר — ייחוד, צניעות, והרחקות
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות: קידושין פ'—פ"ב; סנהדרין כ"א; ברכות כ"ד; רמב"ם הלכות איסורי ביאה
פכ"ב; טור ובית יוסף אבה"ע סי' כ"א—כ"ה; שו"ע ורמ"א; ש"ך; חלקת מחוקק,
בית שמואל; דבר הלכה; יביע אומר.

* א. ‡ ייחוד — תוקפו

** ‡ המחלוקת
- *ייחוד עם אשת איש* :: ‡ מדאורייתא — נלמד מ"כי יסיתך אחיך... בן
  אמך" (רמב"ם ⚠).
- *ייחוד עם פנויה* :: ‡ תקנת דוד ובית דינו — מדרבנן.
- ‡ *ייחוד עם עריות* :: מדאורייתא.

** ‡ מקורו
"ובית דינו של דוד גזרו על ייחוד הפנויה" (סנהדרין כ"א ע"א) — לאחר
מעשה אמנון ותמר.

* ב. ‡ מתי אין איסור ייחוד

** 1. ‡ בעלה בעיר
- ‡ *"בעלה בעיר — אין חוששין לה משום ייחוד"*.
- ‡ *הסברא* :: מירתתא, שמא יבוא.
- ‡ *התנאים* :: —
  - שיהא *בעיר* ממש, ולא רחוק.
  - שיוכל *לבוא בכל שעה*.
  - ‡ *ולא כשידוע שלא יבוא*.
- ⟐ *בזמננו* :: — האם טלפון נייד עושה "בעלה בעיר"? ‡ יש שדנו
  שכן, כשיודעת שיכול להתקשר בכל רגע. ⚠

** 2. ‡ פתח פתוח לרשות הרבים
- דלת פתוחה לרשות הרבים — אין ייחוד.
- ‡ *ואף פתח נעול שיש לאחרים מפתח*.

** 3. ‡ אשתו עמו
- *"אשתו משמרתו"* — אשתו של האיש נמצאת — אין ייחוד.

** 4. ‡ שלושה בני אדם
- ‡ *איש אחד עם שתי נשים* :: ‡ אסור.
- ‡ *אשה אחת עם שני אנשים* :: — ‡ מחלוקת:
  - דעה א' :: מותר, ש"אין אדם חוטא בפני חברו".
  - דעה ב' :: אסור, ובפרט בפרוצים.
  - להלכה :: ‡ מותר בכשרים, ואסור בפרוצים. ⚠
- ‡ *איש אחד עם שלוש נשים* :: ‡ מותר. ⚠

** 5. ‡ קטן וקטנה
- ‡ *קטן פחות מתשע* וקטנה פחות משלוש — אין ייחוד.
- ‡ *"תינוק כבן חמש" משמר* :: — ‡ יש שאמרו שקטן שיודע לדבר
  משמר. ⚠

** 6. ‡ בעל אחר
- ‡ *ייחוד עם אשה כשבעלה ישן* :: ‡ אינו משמר.

* ג. ‡ קרובים

** ‡ מי מותר בייחוד
- *אב עם בתו*, *אם עם בנה*, *בעל עם אשתו*.
- ‡ *אח ואחות* :: — ‡ מותרים ב*עראי* ואסורים ב*קבע*. ⚠

** ‡ אשת אביו וחמותו
- ‡ אסורים בייחוד.

* ד. ‡ ייחוד בזמננו — יישומים

| המצב                        | הדין                                    |
|-----------------------------+-----------------------------------------|
| מעלית                       | ‡ זמן קצר — יש מקילים; ורבים מחמירים    |
| נסיעה במכונית               | ‡ ביום ובדרך מיושבת — יש מקילים         |
| משרד עם דלת פתוחה           | מותר                                    |
| חדר עם חלון לרה"ר           | ‡ יש מקילים                             |
| בית עם מצלמות               | ‡ יש שדנו להתיר                         |
| רופא ומטופלת                | ‡ צריך דלת פתוחה או נוכח נוסף           |
| מורה ותלמידה                | ‡ כנ"ל                                  |

** ‡ להלכה
- אשכנזים :: מחמירים ברוב המקרים; ובמעלית לזמן קצר — יש מקילים.
- ספרדים :: הגר"ע יוסף הקל בכמה מן המקרים (מעלית לזמן קצר,
  נסיעה ביום בדרך מיושבת), ובלבד שלא יהיו פרוצים. ⚠

* ה. ‡ נגיעה

** ‡ תוקפה
- *נגיעה של חיבה* בעריות :: — ‡ מחלוקת הרמב"ם והרמב"ן:
  - *הרמב"ם* ⚠ :: *מדאורייתא* — "לא תקרבו לגלות ערוה" לאו נפרד.
  - *הרמב"ן* ⚠ :: מדרבנן, ו"לא תקרבו" אסמכתא.

** ‡ נגיעה שאינה של חיבה
- ‡ אסורה מדרבנן.
- ‡ *לחיצת יד* :: — ‡ אסורה; ובמקום *איבה גדולה* יש שדנו, ורוב
  הפוסקים אסרו. ⚠

** ‡ רופא
- ‡ מותר לרופא לטפל, שאין זו דרך חיבה ואין הרהור במלאכתו.

* ו. ‡ קול, שיער, וראייה

** 1. ‡ "קול באשה ערוה"
- ‡ *קול זמר* :: אסור.
- ‡ *קול דיבור* :: מותר.
- ‡ *הקלטה* :: — ‡ מחלוקת; יש מקילים כשאינו רואה אותה. ⚠

** 2. ‡ "שער באשה ערוה"
- שיער *אשת איש* — ערוה, וחייבת לכסותו.
- ‡ *פנויה* :: ‡ אינה חייבת.
- ‡ *כמה מגולה* :: — ‡ "טפח באשה ערוה".

** 3. ‡ ראייה והסתכלות
- *"ולא תתורו אחרי לבבכם ואחרי עיניכם"*.
- ‡ *הסתכלות לשם הנאה* :: אסורה מדאורייתא.
- ‡ *ראייה בעלמא* :: ‡ מותרת.

* ז. ‡ צניעות

** ‡ שיעורי הכיסוי
- ‡ *"טפח באשה ערוה"* — במקומות המכוסים.
- ‡ *זרוע, שוק, וצוואר* :: ‡ צריכים כיסוי — לפי הראשונים.
- ‡ *"דת יהודית"* :: מנהג הצניעות שנהגו בנות ישראל, ויש לו תוקף.

** ‡ ההבחנה
- *"דת משה"* :: מדאורייתא.
- *"דת יהודית"* :: מנהג בנות ישראל — ‡ ויש בו חיוב.

* ח. ⟐ סדר הבירור בשאלת ייחוד

1. האם הם *ערוה* זה לזה?
2. האם יש *פתח פתוח לרשות הרבים*?
3. האם *בעלה בעיר*?
4. האם יש *שומר* — אשתו, קטן, אדם נוסף?
5. כמה אנשים — *איש אחד ואשה אחת*, או יותר?
6. האם הם *קרובים*?
7. האם *עראי* או *קבע*?
8. האם הם *כשרים* או *פרוצים*?
9. *לפי איזה מנהג* — ובספק, מחמירים.

* ט. ‡ הערה למורה הוראה

סוגיא זו נוגעת ליחסי אנוש, ולעתים ההחמרה בה גורמת ל*נזק ממשי*
בפרנסה, ברפואה, וביחסי חברה. ולכן:

#+begin_quote
*יש להורות בה בזהירות כפולה — לא להקל שלא כדין, ולא להחמיר
במקום שגורם נזק.*
#+end_quote

וכל מקרה לפי עניינו, ולפי המקום והזמן והאנשים.
