* א. ‡ היסוד: יבום קודם או חליצה? (אה"ע קס"ה)

‡ "מצות יבום קודמת למצות חליצה" — *וי"א שמצות חליצה קודמת*
(ס"א).

** ⟐ המסגרת המעשית (הרמ"א)
| מצב                                        | הדין                                    |
|---------------------------------------------+------------------------------------------|
| אינה רוצה להתייבם לשום אח בלי טענה         | דינה **כמורדת** (למ"ד יבום קודם)        |
| אין לה דין מורדת אם אינה רוצה              | (למ"ד חליצה קודמת)                     |
| אין כופין אותו לחלוץ                        | אלא **מטעין אותו** — "חלוץ ע"מ שתתן לך מנה" |
| שניהם רוצים ביבום                          | אין מניחים — **אא"כ ניכר שמכוונים לשם מצוה** |
| נתן עיניו בממון                            | המנהג: אין כופין כלל — **מפשרים**, כתקנות הקהילות |
| אומר שאינו רוצה לא לייבם ולא לחלוץ         | **כופין אותו**                         |

** נדרה הנאה / הקדישה עצמה
נדרה הנאה מהיבם (אף בחיי בעלה) :: כופין שיחלוץ. ואם **היא
גרמה** שאסורה (התקדשה לאחר, רקקה לפני האחים) :: אין לה דין
מורדת — הואיל והיא גרמה.

** כתובתה
כל יבמה שדינה שתחלוץ :: נוטלת כתובתה (ושמין לה בגדים כאלמנה);
ואף במומי היבם :: "לאחיך הייתי יכולה לקבל — **ולך איני
יכולה**". ותקנות הקהילות :: בפשרה יחלקו כל הנכסים, והחצי
שמגיע — **לחולץ לבדו** ("עיקר התקנה היתה כדי שיתרצו בחליצה").

* ב. ‡ מאמר וקידושי יבמה (קס"ו)

- מן התורה :: אין צורך בקדושין — ביאה לבדה קונה.
- **תקנת חכמים** :: לא יבא עליה עד שיקדשנה בפני עדים בכסף או
  בשטר — "**והוא נקרא מאמר**."
- פרוטה בקדושי אחיו :: מקודשת — "**דהוי כמלוה ופרוטה**"
  (ריב"ש).
- צריכה **חופה** אחר קדושין; מאמר ע"י שליח — כדין.
- בא עליה בלא מאמר :: קנה — ואין צורך לחזור ולקדש; **ומכין
  אותו מכת מרדות** — ודוקא שבא בפני עדים.
- אין עושין מאמר אלא **מדעתה** (וקטנה — מדעת אביה).
- כתובתה :: על נכסי **בעלה הראשון**; ואם אין לו — על נכסי היבם.

** ביאות שקונות (ס"ז—ס"ט)
- קנה אפילו ב**העראה** — בשוגג, לשם זנות, אנוס ע"י כותים,
  מזיד/שוגג בכל ערב, ערה או ישנה.
- *בד"א?* כשנתכוין לשם ביאה בעלמא — ואפילו לביאת בהמה; **אבל**
  שלא נתכוין כלל (ישן, שיכור, נתכוין להטיח בכותל) — לא קנה;
  וב**אבר מת** — לא קנה.

* ג. ‡ קטנים (קס"ז)

| מי                    | קנין/חליצה                                  |
|-----------------------+----------------------------------------------|
| קטן פחות מבן ט'      | אין ביאתו כלום                              |
| מבן ט' ויום          | ביאתו קונה **כמאמר בגדול**                  |
| אשה דעלמא            | ביאה אינה קונה כלל                          |
| יבם קטן              | אינו יכול לגרש עד שיגדיל ויבא עליה          |
| קטן — חליצה          | מבן **י"ג ויום** ובדקוהו והביא שתי שערות    |
| קטנה                 | ביאה קונה מבת **ג'**; חליצה מבת **י"ב** ובדקוה |

** טענת "לא נבעלתי" (ס"ו)
בתוך ל' יום :: נאמנת — וכופין אותו שיחלוץ לה (הואיל וקדם
וגירשה בגט); אם עוד לא גירש — כופין שיבעול **או יחלוץ
ויוציא בגט**; לאחר ל' — מבקשים ממנו; והוא מודה שלא בעל ::
כופין שיחלוץ.

* ד. אחר היבום — כסדר נכסים (קס"ח)

- הרי היא **כאשתו לכל דבר**: מוציא בגט, מחזיר.
- אין היבם רשאי **למכור מנכסי אחיו** — שכתובתה עליהם.
- פירות מחוברים / תלושין / מעות :: ימכרו וילקח בהם **קרקע**
  והוא אוכל פירות; וכל זמן שלא כנסה — המטלטלין ליד **ב"ד או
  אפוטרופוס** (רמ"א).

* ה. ‡ חליצה — עיקרי הפרוצדורה (קס"ט)

1. **ג' דיינים** ישראלים — לא קרובים זה לזה ולא ליבם וליבמה;
   אפילו הדיוטות, רק שידעו להקרות.
2. **אסור ליקח שכר מחליצה** :: "הנוטל שכר לדון — דיניו בטלין";
   ודרש מוסיף: ראיתי רב שנוטל שכר הרבה מן החליצה וסומך עצמו
   שמוכר לו סנדל החליצה — "*קולא גדולה היא בעיני, ושומר נפשו
   ירחק מזה*" (ד"ע).
3. לכתחילה **מוסיפים ב'** על הג'; קובעים מקום; **ביום** ולא
   בלילה; לא בשבתות וימים טובים.
4. צריך שיכירו שהוא אחי המת ושהיה בעולמו וזאת אשת המת —
   ומספיק **עד אחד**, אפילו קרוב או אשה או קטן מכיר ונבון.
5. שידעו שיש **צ' יום** ממיתת הבעל; שהיבם בן י"ג+ והיבמה בת
   י"ב+ והביאו שתי שערות אחר הזמנים; ומעידים על השנים — רק
   ע"פ עדים כשרים (ויש הסמכות בריבוי שערות וקומה).
6. לכתחילה — **מעומד**; בדיעבד מיושב — כשר; וחולה — מיושב.

* ו. ‡ ‡ סדר העריות בנפילה — הסולם המכריע

| איסור היבמה על היבם           | דינה                | צרתה                       |
|-------------------------------+---------------------+-----------------------------|
| **כרת** (חוץ מנדה)            | **פטורה — מותרת לזר בלא חליצה** | אף הצרות פטורות לגמרי |
| **לאו / עשה / שניות דרבנן**  | **חולצת ולא מתייבמת** | או חולצת או מתייבמת       |

- ובחולצה בלאו/עשה :: חליצתה **אינה פוטרת צרתה**; אבל
  חליצת **צרתה** פוטרת אותה. ואם עבר ובא עליה :: קנאה
  ונפטרה צרתה.
- **ספק ערוה** (על בעל או על יבם, ספק קידושין, ספק מיאון
  אחר מיתה) :: **חולצת ולא מתייבמת**.
- סוטה (זינתה בעדים וברצון ומת בלא זרע) :: כערוה — פטורה
  וצרתה.
- איילונית :: כאילו אינה; והטועה שייבם ונמצאה — תצא **בלא גט
  והולד ממזר** ⚠ (וזהו מקרה קיצון — עי' פוסקים).

** ‡ איסור עולמי — שעת הנפילה היא הכל (קע"ה)
- אסורה בשעת נפילה משום ערוה :: **אסורה עולמית** — אפילו
  אם **יפקע** האיסור (שני אחים נשואים שתי אחיות; מתה אשתו
  של זה שנשוי אחותה — אף על פי כן אסורה, בשניה ובשלישית
  נפילה).
- מותרת בשעת נפילה :: אפילו נאסרה אח"כ — **אם פקע האיסור,
  חוזרת להתירה**.
- שנים נשואים שתי אחיות ומתו שניהם **ולא נודע מי קודם** ::
  זיקה על שתיהן — **חולצות ולא מתייבמות**.

* ז. ⟐ המנהג — וגבולותיו

בכל ישראל נהגו **חליצה בלבד**; ובקודקס כאן נמצא היסוד: הכרעת
"יבום קודם" במחלוקת, והרמ"א — *"אין כופין... אלא מפשרים"*,
עם תקנות הקהילות שהפשרה כולה נתלית בחליצה. ובכל שאלה
מעשית (זיקה, ספקות, אגונות) — **לבתי הדין המומחים** ⚠.

* ח. ⟐ סדר הבירור

1. מת? זרע קיימא? (אה"ע קנ"ו) — ולא, נפלה לאחים.
2. מי ראשון? גדול; ואם מת — הבא אחריו.
3. איזה איסור על היבם? → **כרת**: פטורה ומותרת לזר;
   **לאו/עשה/שניות**: חליצה בלבד; **ספק**: חליצה בלבד.
4. רוצים ביבום? → רק לשם מצוה; אחרת — פשרה וחליצה.
5. צ"י מהמיתה; ג' דיינים (+ב'); ביום; בלי שכר; מעומד.
6. אחר חליצה — כתובתה מנכסי בעלה הראשון.
