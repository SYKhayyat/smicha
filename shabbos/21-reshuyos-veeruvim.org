* א. ‡ ארבע רשויות (או"ח שמ"ה)

** הרשויות
| רשות            | הגדרה                                                | איסור          |
|------------------+-------------------------------------------------------+-----------------|
| **רשות היחיד**  | מוקף מחיצות י' ויש בו ד' על ד' (חריץ/תל כדינם)       | חיוב סקילה     |
| **רשות הרבים**  | "רחובות ושווקים הרחבים **י"ו אמה**, ואינם מקורים, מפולשים משער לשער" | חיוב סקילה     |
| **כרמלית**      | "מקום שאין הילוך לרבים" — ים, בקעה, אצטבא, קרן זוית | דרבנן          |
| **מקום פטור**   | אין בו ד' על ד' וגבוה מג' (או חריץ כזה)              | מותר           |

‡ *הרמ"א על רשות הרבים*: "ויש אומרים שכל שאין **ששים רבוא**
עוברים בו בכל יום — אינו רשות הרבים."

| מקום ברה"ר                        | גובה/רחב                | דינו         |
|------------------------------------+--------------------------+---------------|
| דבר שעל קרקע                      | עד ג'                   | כקרקע — רה"ר |

|                                    | ט' מצומצמים ורבים מכתפים | רה"ר        |

והנוטל מים מעל פני נהר :: כרמלית עד י', ומקום פטור מעל י'.

* ב. יציאות — עיקרי החיוב (שמ"ז)

מן התורה :: רק **עקירה מרשות לרשות** (עקר+הניח); פשט יד
שני בני אדם משני צדדים :: פטורים — **אבל אסור מדרבנן**.

* ג. ראשו ורובו (ש"

- עומד ברה"י ומוציא ידו לרה"י ומטלטל שם :: מותר — בלבד
  שלא יעבירם ד' אמות; *ומותר ליטול מפתח מרה"י לרה"ר ולפתוח
  שם.*
- **שתיה** :: לא יעמוד באחת וישתה בחברתה — אלא אם כנס ראשו
  ורובו; אבל ב**כרמלית** — מותר מכל מקום; וכלים שאינם נאים ::
  מותר אף בצואר בלבד.

* ד. ‡ מחיצות (שס"א—שס"ב)

** מחיצה לטלטל ולדיר
- מחיצה שאינה לדור (לצניעות, לשמור) :: **מחיצה לטלטל** —
  אבל אינה לעשות מה שבתוכה (אינה "מוקף לדיר").
- "**כל מחיצה שאינה יכולה לעמוד ברוח מצויה — אינה מחיצה**."
- תל ג' ומחיצה עליו עד י' :: כשרה להכל; ספינה :: כמוקפת
  לדירה; כפאה לזופתה :: אינה רה"י.

** מחיצה של בני אדם
כשרה אפילו מהלכים — *בלבד שלא ידעו שהועמדו לשם*.
‡ הרמ"א: "ואין לעשות מחיצה של בני אדם רק **בשעת הדחק**;
ואם שכח דבר ברה"ר — **עדיף להוליך שם תינוקות** שיביאוהו
בלא מחיצה, מלעשות מחיצה של בני אדם."

** פרוץ ועומד, צורת פתח
- **פרוץ מרובה על העומד** :: אסור — אלא אם כל פרצה פחותה
  מג'.
- פרוץ כעומד :: מותר — בלבד שלא יהא פרוץ א' **יותר מעשר**
  (כפתח).
- **צורת פתח** לפירצה מעשר :: הש"ע — מהני אפילו בבקעה;
  ***ולהרמב"ם — אינו מועיל לפרצה מעשר*** אלא אם עומד מרובה
  (רמ"א).

* ה. ‡ מבוי ושיתופו (שס"ג, תפ"ו)

- מקום שיש בו **ג' מחיצות** (ופתח לרה"ר) :: אסרו חכמים
  לטלטל — עד שיעשה **שום תיקון ברביעית** (לחי או קורה —
  פרטיהם באו"ח שס"ג—שס"ה).
- **שיתוף מבואות** :: "אסרו חכמים לטלטל מן החצירות למבוי,
  והתירוהו ע"י **שיתוף** — שגובין פת... מכל חצר וחצר
  ונותנים בא' מן החצירות"; יכולים ליתנו **באויר החצר** או
  בבית שאין לו ד' על ד' — **ולא באויר המבוי**.
- שיעור :: **שני סעודות**; משתתפין בכל מיני מאכל — חוץ
  מגודגדניות, תבלין, פולין יבשים, מים ומלח לבדם (וי"א
  בתבלין כן).
- ואפילו באוכל **שאינו ראוי לו** — אם ראוי לשום אדם
  (לנזיר ביין).

* ו. ‡ עירובי חצרות (תס"ז—ש"ע)

** מי מערב, ומי אוסר
- **אשתו מערבת לו שלא מדעתו** — אפילו מיחה; *ובמה דברים
  אמורים?* כשהוא **אוסר** (אין פתח אלא לחצר זו) או רגיל
  לערב; אינו אוסר ואינו רגיל :: אינה מערבת; כל זמן שלא
  מיחה בפירוש — מערבת ("דמסתמא ניחא ליה").
- אין יכולה **לזכות משלו לאחרים** שלא בידיעתו.
- בני החצר :: אין נוטלין מביתו בעל כרחו אם אינו רגיל —
  אבל **בית דין כופין או יורדים לנכסיו**.

** מקום הדירה
- "***מי שאוכל במקום א' וישן במקום אחר — מקום אכילתו הוא
  העיקר.***"
- האוכלים כלם על **שלחן אחד** :: כאנשי בית א' — אין צריכים
  עירוב; וכן מרובים בחדר אחד איש על שלחנו.
- דר בבית שער/אכסדרה :: אינו אוסר (אינו דירה); בבית התבן
  וכיו"ב :: אוסר.
- חמש חבורות בטרקלין :: עוברים זה ע"י זה — שני הפנימיים
  לבד מערבים; ואין מחיצות עד התקרה :: די בעירוב א' לכולם.

* ז. ⟐ סדר הבירור

1. איזו רשות? → הטבלאות של ס"א; וספק רה"ר — לחומרא ככרמלית.
2. הוצאה? → עקירה והנחה ממש לתורה.
3. פרצה/מחיצה? → פרוץ-כעומד וצורת פתח — וטעמו של הרמב"ם
   לחומרא.
4. מבוי? → תיקון ברביעית + שיתוף שני סעודות במקום משתמר.
5. עירוב חצרות? → דעת האוסר, ומקום אכילתו הוא הקובע.
6. ותמיד: עירוב תחומין — [[file:02-eruvin-techumin.org][קובץ 02]],
   ועירוב עיר מודרני — **לבתי הדין המיוחדים לזה** ⚠.
