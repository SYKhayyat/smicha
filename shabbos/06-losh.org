#+TITLE: שבת — לש
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות: שבת י"ח, קנ"ה ע"ב—קנ"ו ע"א ⚠; רמב"ם הלכות שבת פ"ח, פכ"א;
טור וב"י או"ח סי' שכ"א ס"ט⚠ וסי' שכ"ד; שו"ע ורמ"א; מג"א, ט"ז, מ"ב.

* א. ‡ יסוד המלאכה

** ההגדרה
*חיבור חלקים דקים לגוף אחד ע"י משקה.*

** ‡ שני יסודות במלאכה — וזהו שורש כל המחלוקות

*** יסוד א' — "גיבול"
המלאכה היא *מעשה הערבוב והגיבול* — ההנעה שמאחדת את החלקים.

*** יסוד ב' — "נתינת המים"
המלאכה היא *עצם החיבור* הנוצר, ואף בלא גיבול.

** ‡ נפקא מינה מרכזית
הנותן מים לקמח ואינו מגבל כלל — הנחת המים לבדה:
- ליסוד א' :: אין כאן לישה עד שיגבל.
- ליסוד ב' :: כבר עבר, שנוצרה תערובת.

*להלכה:* חוששים לשניהם — ולכן אסור אף ליתן מים לקמח.
(רמ"א או"ח סי' שכ"א סט"ז ⚠)

* ב. ‡ בלילה עבה ובלילה רכה

** ההבחנה
- *בלילה עבה* :: הנעשית גוש אחד המחזיק צורתו.
- *בלילה רכה* :: נשארת נוזלית ואינה מתלכדת.

** ‡ המחלוקת
- דעה א' :: אין לישה אלא ב*בלילה עבה*, שרק שם נוצר גוף אחד.
- דעה ב' :: אף ב*בלילה רכה* יש לישה מדרבנן, שנעשה תערובת.
- דעה ג' :: אף ברכה יש לישה מדאורייתא. ⚠

** להלכה
- *בלילה עבה* :: אסורה מדאורייתא.
- *בלילה רכה* :: אסורה מדרבנן, ומותרת ב*שינוי*.
- *בלילה רכה מאוד* (נוזל גמור) :: מותרת. ⚠

* ג. ‡ סדר נתינת המים — הכלי לכל ההיתרים

** הכלל
כשמותר לעשות בלילה רכה בשינוי, השינוי הוא ב*סדר*.

** ‡ המחלוקת בסדר
- שיטה א' :: יתן ה*משקה תחילה* ואח"כ את המוצק — שכך אינו דרך לישה.
- שיטה ב' :: יתן את ה*מוצק תחילה* ואח"כ המשקה, ואח"כ יערב בשינוי.
- ⟐ *להלכה* :: הסדר המקובל — משקה תחילה, ואח"כ המוצק, ומערב בשינוי
  (בקצה הכף, או בשתי וערב, או בניעור הכלי). ⚠

** ‡ שינויים המועילים
1. שינוי בסדר הנתינה.
2. ערבוב ב*שתי וערב* (ולא בסיבוב).
3. ערבוב ב*ניד הכלי* ולא בכף.
4. ערבוב באצבע או בקצה הכף.
5. פיזור המשקה במקום שפיכה מרוכזת.

* ד. ‡ אין לישה אחר לישה

** הכלל
דבר ש*כבר נילוש* — אין בו לישה שנייה.

** ‡ המחלוקת
- דעה א' :: אין לישה אחר לישה, כשם שאין טוחן אחר טוחן.
- דעה ב' :: יש לישה אחר לישה, שהלישה השנייה יוצרת גוף חדש.
- להלכה :: מחמירים, ומקילים במקום צורך ובשינוי. ⚠

** ⟐ נפקא מינות
1. הוספת מים לעיסה שכבר נילושה.
2. ערבוב סלט ביצים או טונה שכבר נילוש — יש מקילים, ורבים מחמירים
   ומצריכים שינוי. ⚠

* ה. ‡ מה נחשב "לישה"

** ‡ שני תנאים
1. ה*מוצק* — חלקים דקים ונפרדים (קמח, אבקה, פירורים).
   - ולא חתיכות גדולות, שאין בהן לישה כלל אלא ערבוב.
2. ה*משקה* — נוזל המחבר.

** ⟐ נפקא מינות
- *סלט ביצים / טונה / חצילים* :: יש בהם לישה, שהחלקים דקים.
  ולכן — שינוי בסדר ובערבוב.
- *סלט ירקות חתוך גס* :: אין בו לישה, שהחתיכות גדולות ואינן מתלכדות.
- *דייסה לתינוק* :: לישה גמורה. יש ליתן המים תחילה ולערב בשינוי.
- *ערבוב סוכר בתה* :: אין בו לישה, שהסוכר נמס ואינו נעשה גוש.
- *ממרח (חומוס, טחינה) מוכן, ומוסיף מים* :: לישה אחר לישה — בשינוי.
- *אבקת חלב במים* :: אין בו לישה, שנעשה נוזל גמור.

* ו. ‡ תולדות ומלאכות סמוכות

| המלאכה | מהותה                          | ההבדל מלש            |
|--------+--------------------------------+----------------------|
| לש     | חיבור דקים ע"י משקה            | —                    |
| ממחק   | החלקת פני דבר                  | אין חיבור            |
| בונה   | ‡ בנין באוכלין — מחלוקת        | אין משקה             |
| ממרח   | ‡ תולדת ממחק                   | על גבי דבר אחר       |

** ‡ בנין באוכלין
- דעה א' :: *אין בנין באוכלין* — אין מלאכת בונה במאכל.
- דעה ב' :: יש, במקום שעושה צורה קבועה.
- להלכה :: אין בנין באוכלין; ומכל מקום נזהרים מלעשות צורות. ⚠

** ‡ ממרח
מירוח חמאה או גבינה על הלחם:
- ‡ מחלוקת :: יש בו משום *ממחק* — החלקת פני הדבר.
- להלכה :: מותר, שאין כוונתו להחליק אלא לאכול. ומירוח בכוונה להחליק
  — יש להחמיר. ⚠

* ז. ⟐ סיכום מעשי

1. *אין לתת משקה למוצק דק* — אף בלא ערבוב.
2. בבלילה *עבה* — אסור לגמרי.
3. בבלילה *רכה* — מותר בשינוי: משקה תחילה, וערבוב בשתי וערב או בניד.
4. *נוזל גמור* — מותר בלא שינוי.
5. *חתיכות גסות* — אין בהן לישה כלל.
6. בכל ספק — יעשה בשינוי, וירויח.
