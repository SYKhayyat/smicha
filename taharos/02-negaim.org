#+TITLE: נגעים — מראות הצרעת ויסודי הבדיקה
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות (מחוץ לשו"ע): רמב"ם הל' טומאת צרעת פ"א (נבדק מהטקסט).

* א. ‡ הגדרת הלובן

"צרעת עור הבשר הוא שילבין מקום מן העור, **ותהיה הלבנונית
כקרום ביצה ומקרום ביצה ולמעלה**."
- לבנונית **דהה מקרום ביצה ולמטה** :: אינה צרעת — אלא
  **בהק** הוא.

* ב. ‡ ארבעת המראות

| מראה                  | שם                        | דוגמתו            |
|------------------------+----------------------------+--------------------|
| לובן עז ביותר         | **בהרת**                   | **כשלג**          |
| דהה ממנו מעט           | **שאת**                    | **צמר נקי של כבש בן יומו** |
| דהה מן השאת           | **ספחת** (תולדת הבהרת)    | **סיד ההיכל**     |
| דהה מסיד ההיכל מעט    | (תולדה)                    | **כקרום ביצה**    |

* ג. ‡ הצטרפות

"ארבע מראות נגעים אלו **כולן מצטרפין זה עם זה** — בין
להקל בין להחמיר; בין בתחלת ראיית הנגע, בין בסוף השבעה,
בין לאחר שנפטר המצורע או נחלט."
- ואפילו נגע שהוא **מעורב** :: מקצתו כבהרת ומקצתו כשאת
  וכספחת — הכל כמראה אחד.

* ה. ‡ שער לבן — סימן טומאה (פ"ב)

- **אין פחות משתי שערות**; וארכן :: כדי **שיהיו נטלות
  בזוג**.
- *וטהור* :: אחת ארוכה ואחת קצרה משיעור זה; אחת שחורה
  ואחת לבנה; אחת מלמטה ונחלקה מלמעלה ונראית כשתים;
  עקרן משחיר וראשן מלבין.
- **שתי לבנות בתוך הנגע אפילו מפוזרות** — סימן טומאה,
  **אפילו בגריס מצומצם** ("אין מקום שער השחור ממעיטו");
  בגוף הבהרת או בסופה — טמא; **בצדה מבחוץ** — טהור.
- **לובן השערות מטמא בכל מראה** — אפילו לובן דהה ביותר.
- **אין סימן עד שיהיה בגוף הבהרת** :: שחין/מכוה/בהק
  **בתוך** הבהרת ושתי לבנות בתוכו :: **אינן סימן** —
  ויסגיר אף שהבהרת מקפת את השחין; **והלכו להן** השחין
  וכיו"ב (או נסמכין/חולקין) ונמצאו השערות בגוף הבהרת
  בסוף שבוע ראשון או שני :: **מוחלט**; ואם לא הלכו —
  **יפטרנו**.

* ז. ‡ מחית בשר חי (פ"ג)

- **אין המחיה סימן עד שתהא כעדשה מרובעת** — שיעורה ::
  **צמיחת ארבע שערות, שתים ארך ושתים רחב**; *ובמה
  דברים אמורים?* באמצע הבהרת והבהרת **מקפת אותה** מכל
  צד ויתרה עליה **רחב שתי שערות**; בצד הבהרת :: אינה
  סימן.
- **מטמאה בכל מראה** — אדם/שחור/לבן — **ושלא יהיה הלובן
  מארבעת המראות**.
- **אינה סימן עד שתהא בגופה של בהרת** :: בהרת באמצע שחין
  ומחיה בתוך השחין — אף שהמחיה באמצע הבהרת :: אינה
  סימן.
- ⟐ "**לעולם** — בין שקדמה המחיה בין שקדמה הבהרת" —
  שלא נאמר בה "**והיא הפכה**": אין צריך לשניהן — **כל
  אחד מהן סימן טומאה**.

* ח. ⟐ סדר הבירור

1. עד היכן הלובן? → מקרום ביצה ולמעלה; למטה — בהק.
2. איזה מראה? → לפי הטבלה — ומצטרפין.
3. ותמיד: הכהן הוא המכריע ⚠ — וכל דיני השבעה והפטר
   (בראש זקן, שער פנים, מכוון בשר חי) — להרחבה הבאה.
