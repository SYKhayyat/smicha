#+TITLE: טהרות — יסודי הטומאה: מת, אוכלין, ואבות הטומאה
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות (מחוץ לשו"ע): רמב"ם הל' טומאת מת פ"א, הל' שאר
אבות הטומאות פ"א, והל' טומאת אוכלין פ"א (נבדקו מהטקסט);
ולעומק — לחם משנה על המקומות (במדף).

* א. ‡ טומאת מת — שלש דרכים

"המת מטמא ב**מגע, ובמשא, ובאוהל** — טומאת שבעה."
- **מגע ואוהל** :: מפורשין בתורה ("הנוגע במת... שבעת ימים";
  "כל הבא אל האהל וכל אשר באהל").
- **משא** :: מפי השמועה — והרמב"ם מביא **ק"ו** מנבילה
  ("והנשא את נבלתם"): אם נבילה — טומאת ערב — מטמאה במשא,
  **המת לא כל שכן**; ומסקנתו :: "אין טומאת משא במת
  מדברי סופרים אלא **דין תורה**" — וכדרך ששתק הכתוב.

** גדרי מגע
- מגע :: נגע **בבשרו** בטומאה — בידו, ברגלו, **אפילו
  בלשונו**; ונראה לרמב"ם :: אפילו בצפרניו ובשיניו —
  **כשהם מחוברים**.
- *ולא נטמא* :: תחב טומאה בכוש והכניסה לגרונו בלא נגיעה
  בלשונו, או למעי של בהמה.
- **קרום שעל המכה** :: כעור הבשר; **כשות שעל הקטן** ::
  אינה כעור הבשר — לא נטמא.

* ב. ‡ טומאת אוכלין — ההכשר

** מי מקבל טומאה
"כל אוכל **המיוחד למאכל אדם** (לחם, בשר, ענבים, זיתים) ::
מקבל טומאה; וכל שאינו מיוחד :: טהור — **אא"כ חשב עליו**."
*ואינו מקבל טומאה* — עד שיבלל תחלה באחד משבעה משקין ::
**וזהו ההכשר** ("וכי יתן מים על זרע").

** שבעת המשקין
**מים, טל, שמן, יין, חלב, דם, דבש.**
- אינן מכשירין עד שיפלו **ברצון הבעלים**; **ולא סרוחין**.
- הוכשר אפילו יבש ונגוב :: מקבל טומאה.
- **מי פירות** (תותים, רמונים) :: אינן מכשירין **ואין
  מקבלין טומאה כלל** — שאין משקה מקבל טומאה אלא שבעת
  המשקין בלבד.

* ג. ‡ אבות הטומאה — דרכי ההעברה (הזב וכיוצאיו)

"הזב והזבה והנדה והיולדת — **כל אחד מארבעתן אב
מאבות הטומאות**":
- מטמאין **כלים במגע**;
- מטמאין **אדם במגע ובמשא**;
- מטמאין **משכב ומושב ומרכב מתחתיו** — ועושה אותן **אב
  טומאה**;
- ומטמא **מדף על גבו**.

** והכל שוים
זבה קטנה/גדולה, מחמת עצמה/אונס, זב בעל שתי/שלש ראיות ::
"טומאת כולן **שוה** לטמא אחרים." ואף :: **קטנה בת יום
אחד** — מטמאה בנדה; בת י' — בזיבה; בג' ויום — מטמאה את
בועלה; **קטן בן יום אחד** — מטמא בזיבה; וגרים ועבדים —
מטמאין בנדה ובזיבה.

* ד. ⟐ סדר הבירור

1. איזה אב? → מת (מגע/משא/אוהל), זב וכיוצאיו (אב אמיתי),
   נבילה ושרץ (ערב).
2. כלי? → מגע בלבד מאבות אלו; והמשכב/מושב — אב בעצמו.
3. אוכל? → מיוחד + הוכשר בשבעת המשקין ברצון; ומי פירות —
   לא.
4. ותמיד: טהרות כולן — הלכות שאין להן גבול ⚠ (והעומק —
   ללחם משנה ולפוסקים).
