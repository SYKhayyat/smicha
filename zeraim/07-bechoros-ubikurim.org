#+LANGUAGE: he

מקורות (מחוץ לשו"ע): רמב"ם הל' בכורות פ"א (נבדק מהטקסט);
ולביכורים עצמן — הל' ביכורים (במדף).

* א. ‡ פטר רחם

"מצות עשה להפריש **כל פטר רחם הזכרים** — בין באדם, בין
בבהמה טהורה, בין ממין החמור; בין שהיו **שלמים בין שהיו
טרפות** — 'קדש לי כל בכור פטר כל רחם' — **וכולן לכהנים**."

* ב. ‡ שלשת הדינים

| בכור              | דינו                                        |
|--------------------+----------------------------------------------|
| **אדם וחמור**     | **נפדים** — ופדיונן לכהנים                  |
| **בהמה טהורה תם** | נשחט **בעזרה** כקדשים קלים; דמו נזרק, אימוריו |
|                   | מקטירין, והבשר **לכהנים**                   |
| **בהמה בעלת מום** | לכהן — **והוא חולין**: אוכלו בכל מקום, מוכרו, |
|                   | ואפילו **מאכילו לנכרי**                     |

- המום :: בין שנולד בו, בין שנפל אחר שהיה תם — הדין שוה
  ("וכי יהיה בו מום פסח או עור... הטמא והטהור יחדו יאכלנו
  **כצבי וכאיל**").
⟐ והסיום הרמב"מי :: "והרי הוא **נכסי כהן**."

* ג. ביכורים

הבאת ביכורים למקדש והקראתם — בהל' ביכורים (במדף); ולמצוות
הארץ כולן — [[file:../yoreh-deah/08-mitzvos-haaretz.org][יו"ד 08]].

* ה. ‡ המומין והבכור (רמב"ם הל' בכורות פ"ב)

- המומים **קבועים הפוסלין קדשים ונפדין עליהן** — אם נפלו
  בבכור :: **נשחט עליהן בכל מקום**; והם ס"ז (בהל' איסורי
  מזבח).
- מה ש**אין הקרבן מן המובחר ואינו ניפדין** :: אין הבכור
  נשחט עליהן ולא קרב — **יעמוד עד שיולד בו מום קבוע**.
- **מום עובר** (או נעבדה בו עבירה / הרג בעד אחד / הוקצה /
  נעשה) :: **ירעה עד שיפול בו מום קבוע**.

** יוצא דופן
"**יוצא דופן והבא אחריו — שניהן אינן בכור**": הראשון ::
אינו פטר רחם; האחרון :: **שקדם אחר**.
- *אפילו* יצאה נקבה דרך דופן **וזכר דרך רחם** — אינו בכור.

* ו. ⟐ סדר הבירור

1. פטר רחם? → זכר בלבד, ואפילו טרפה — לכהן.
2. מאיזה? → אדם וחמור: פדיון; טהורה: קרבן; בעלת מום:
   חולין לכהן.
3. ותמיד: בכור תם — קדשים קלים ממש.
