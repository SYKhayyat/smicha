#+TITLE: מתנות עניים — פאה, לקט, שכחה, פרט ועוללות, ומעשר עני
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות (מחוץ לשו"ע): רמב"ם הל' מתנות עניים פ"א (נבדק מהטקסט);
ערוך השלחן העתיד זרעים סי' א' (נבדק מהטקסט) וסי' י"ד;
משנה פאה א' עם הברטנורא (נבדק); ולמעשר עני בהרחבה — ערו"ה
העתיד י"ד; ולתרומות ומעשרות — [[file:../yoreh-deah/08-mitzvos-haaretz.org][יו"ד 08]].

* א. ‡ המסגרת — הפסוקים והמנין

** המקורות
"ובקצרכם את קציר ארצכם — לא תכלה פאת שדך בקצרך, ולקט קצירך
לא תלקט, וכרמך לא תעולל, ופרט כרמך לא תלקט — **לעני ולגר
תעזוב אותם**" (קדושים); "כי תקצור קצירך בשדך **ושכחת עומר**...
כי תחבוט זיתך, כי תבצור כרמך" (כי תצא).

** המנין (ערו"ה העתיד א', רמב"ם הל' מתנות עניים פ"א)
| מקום        | מתנות                                  |
|-------------+-----------------------------------------|
| **בכרם**    | **ד'** — פרט, עוללות, פאה, שכחה       |
| **בתבואה**  | **ג'** — לקט, שכחה, פאה               |
| **באילנות** | **ב'** — שכחה, פאה (מ"אחריך" שבזית)   |

‡ ומסקנת הת"כ :: "כל מי שמניח לקט שכחה ופאה ומעשר עני — מעלה
עליו הכתוב **כאילו בהמ"ק קיים והקריב קרבנות בתוכו**."

* ב. ‡ אילנות — מדאורייתא או אסמכתא?

‡ המחלוקת היסודית (ערו"ה העתיד א' ס"ד—ה'):
- **ר"ת** :: מן התורה אין פאה אלא ב**דגן, תירוש, ויצהר** —
  ואילנות אסמכתא בעלמא.
- **רמב"ם, ראב"ד, סמ"ג, ורוב המפרשים** :: כל האילנות —
  **דאורייתא**; דדרשינן "**שדך**" — אילן קרי שדה, וזית לאו
  דווקא.
⟐ ופרט ועוללות — דווקא **בכרם** (שניהם מסכימים).

* ג. ‡ חמשת תנאי החיוב — "קציר"

מה שנדרש "**קציר**" (ערו"ה העתיד א' ס"ו—ז', רמב"ם הל' מתנות עניים פ"ב) ::
חייב רק מה שהוא:
1. **אוכל** (יצאו אסטיס, פואה, כמהין ופטריות);
2. **ונשמר**;
3. **גידולו מן הארץ**;
4. **ולקיטתו כאחת** (יצאו **תאנים**);
5. **ומכניסו לקיום** (יצאו **ירקות**).

⟐ *והחיובי היתירים*: **שומים ובצלים** — חייבים (מייבשין
ומכניסין לקיום); **ההפקר** — פטור ("אין לו מי שישמרנו");
והתבואה והקטניות — בכלל. וכל אלו **שוין בפאה, בלקט ובשכחה**.

* ד. ‡ "אין להם שיעור" (משנה פאה א' א, בברטנורא)

- פאה, בכורות, ראיון :: **מדאורייתא אין שיעור** — אבל
  מדרבנן כן (פאה: **לא יפחות מאחד מששים**).
- **גמילות חסדים** :: *בגופו* — אין שיעור; *בממונו* :: יש —
  "**המבזבז אל יבזבז יותר מחומש**" (ברטנורא: חומש הריוח בכל
  פעם).
- **תלמוד תורה** :: אין שיעור — "והגית בו יומם ולילה."
  (ועי' [[file:../talmud-torah/01-yesodei-limud.org][ת"ת 01]].)

* ה. פאה עצמה

- **בסוף בלבד** להפטר :: אף דרבי מחייב בתחלה ובאמצע תורת
  פאה — "לא מפטר אלא אם כן נותן בסוף **שיעור אחד מששים**
  עם מה שנתן באמצע ובתחלה" (ברטנורא; ורמב"ם: בסוף שיעור
  פאת כל השדה).
- שתי שדות בפאה אחת :: רק כשאין ביניהן **בור, ניר, או זרע
  אחר** — ושיעור ההפרדה :: כדי **שלשה תלמים** של המחרישה.

* ו. לקט, פרט, עוללות

- **לקט** :: "כדי נפילה" — ארבעה קבין **לכור זרע** (ל"ס
  סאין); ‡ ומחלוקת ת"ק ורשב"ג :: **אומדן** בכל עת, או
  **קצוב ועומד** (ברטנורא).
- **בענבים** :: אין פוחתין אם אין בציר — **שלשה אשכולות
  שעושין רביעית**.
- **פרט ועוללות** :: הנופלין בשעת הבצירה — לעניים.

* ז. שכחה

- בעומרים ובקמה כאחד; **ובכל האילנות** — "כי תחבוט **זיתך**...
  לא תפאר אחריך" — וזית לאו דווקא (רמב"ם הל' מתנות עניים פ"א).
- ⟐ *שים לב להיפוך*: בשכחה — הקפדה שלא **לחזור** ("לא תשוב
  לקחתו"); בשאר — הנחה פעילה.

* ח. מעשר עני — שיעורי החלוקה

** בגורן (משנה פאה ח', בברטנורא וערו"ה י"ד)
| מין            | כדי שבעו          |
|-----------------+--------------------|
| חטים           | **חצי קב**        |
| שעורים/כוסמין | קב                |
| דבילה          | משקל כ"ה סלעים   |
| יין            | חצי לוג           |
| שמן            | רביעית            |
| קמח/אורז      | רובע הקב          |
| ירק            | ליטרא             |
| חרובים         | ג' קבין           |
| אגוזים/אפרסקין/רמונים | י' / ה' / ב' |
| אתרוג          | אחד               |

- "אם אין... והעניים מרובין" :: נותן לפניהם מה שיש —
  **והן מחלקין ביניהן**.
- **בבית** :: רשות — מחלק כרצונו, אין שיעור.
- ‡ **והחילוק הרמב"מי** (ערו"ה י"ד ס"ה): בגורן :: **אין
  טובת הנאה** — העניים נוטלין **על כרחו**; בבית :: **יש
  טובת הנאה** — נותן לכל עני שירצה.

* ט. ‡ א"י וחוץ לארץ

- מן התורה :: רק **בארץ** ("ארצכם") — כתרומות ומעשרות.
- בחוץ לארץ :: **מדבריהם** — וכך המבואר בחולין קל"ד (לוי
  זרע בכישר... "לעני ולגר תעזוב — ולא לעורבים ולעטלפים").
‡ *והערתו ההיסטורית של הערוך העתיד* (ס"י) :: מעולם לא שמענו
שנהגו פאה בחו"ל — שמא התקנה היתה דוקא כשעסקו באדמה; בדורותינו
שאין עוסקים — מקיימין צדקה במעות, ולפיכך לא תקנו ⚠.

* י. ⟐ הכלל המסכם — אין טובת הנאה

"כל מתנות עניים אלו **אין בהן טובת הנאה לבעלים** — אלא
העניים באין ונוטלין אותן **על כרחן של בעלים**, ואפילו עני
שבישראל מוציאין אותן מידו" (רמב"ם הל' מתנות עניים פ"א ה"ד).
⟐ וזהו הסימן המבדיל מתנות עניים מן **צדקה** — ששם רשות
ביד הנותן (ועי'
[[file:../yoreh-deah/03-kibud-av-tzedakah.org][יו"ד 03]]).

* ק. ⟐ סדר הבירור

1. איזו מתנה? → לפי טבלת המנין (כרם ד' / תבואה ג' / אילן ב').
2. חייב מן התורה? → אילנות: ר"ת נגד רמב"ם; ותמיד חמשת תנאי
   הקציר.
3. שיעור? → דאורייתא אין; דרבנן: פאה חד מששים, לקט כדי
   נפילה, מעשר עני בגורן — כדי שבעו.
4. גורן או בית? → טובת הנאה ושיעור — הפוכים.
5. א"י או חו"ל? → דאורייתא/דרבנן — וערו"ה העתיד בגדרי
   ההנהגה.
6. ותמיד: אין טובת הנאה — והעני גובה.
