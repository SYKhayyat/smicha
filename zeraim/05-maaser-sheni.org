#+TITLE: מעשר שני — ראשי שנים, קדושתו, וגדרי ההפרשה
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות (מחוץ לשו"ע): רמב"ם הל' מעשר שני ונטע רבעי פ"א
(נבדק מהטקסט); משנה מעשר שני א' עם הברטנורא (נבדק);
ולסדר השנים — [[file:02-terumos.org][קובץ 02]]; ולמעשר עני —
[[file:01-matnos-aniyim.org][קובץ 01]].

* א. ‡ הכלל והשנים

"אחר שמפרישין מעשר ראשון בכל שנה — מפרישין **מעשר שני**,
שנאמר 'עשר תעשר'; ובשנה **שלישית וששית** — מעשר עני חלף
מעשר שני" (רמב"ם הל' מעשר שני פ"א).

* ב. ‡ ראשי שנים למעשרות

| ראש השנה ל...          | זמן              |
|--------------------------+-------------------|
| **תבואות, קטניות, ירקות** | **א' בתשרי**     |
| **אילנות**               | **ט"ו בשבט**     |

- "וכל מקום שנאמר **ראש השנה** — הוא א' בתשרי."
- **תבואה שהגיעה לעונת המעשרות קודם ר"ה של שלישית** ::
  אף שנגמרו ונאספו בשלישית — **מעשר שני**; ואם לאו — מעשר
  עני.
- **ירק בשעת לקיטתו עישורו** :: נלקט בר"ה של שלישית ::
  מעשר עני — אף שבא לעונת המעשרות ונגמר בשנייה; נלקט
  ברביעית :: מעשר שני.

* ג. ‡ החרובים — והחידוש הרמב"מי

"החרובין אף שחנטו קודם ט"ו בשבט — מתעשרין **להבא**, הואיל
ומתעשרין **מדברי סופרים**."
‡ *ונראה לרמב"ם* :: דוקא **חרובי צלמונה** וכיו"ב — שאין
ראויין למאכל רוב האדם (והם המתעשרים דרבנן); **שאר החרובים
— כשאר פירות האילן**.

* ד. ‡ קדושת מעשר שני (משנה א' א', בברטנורא)

- "**מעשר שני אין מוכרין אותו**" — אפילו להוליכו לירושלים,
  לפי שהוא קודש.
- **וסתם מתניתין כר"מ** :: "מעשר שני **ממון גבוה** הוא."
- "**ואין מחליפין אותו**" — לא יאמר: הילך יין ותן לי שמן,
  שמן ותן לי יין.
⟐ *ומכאן היסוד*: מעשר שני — קדושת **דמים** (נפדה ונאכל
בירושלים), לא קדושת הגוף; ופרטי הביאור והפדיון — להרחבה
הבאה ⚠.

* ה. ‡ מעשר שני בזמן הזה (רמב"ם הל' מעשר שני פ"ב)

- נאכל לבעליו **לפנים מחומת ירושלים**; נוהג בפני הבית
  ושלא בפני הבית — **אבל אינו נאכל בירושלים אלא בפני
  הבית** ("מעשר דגנך תירשך ויצהרך ובכרת בקרך וצאנך" —
  מפי השמועה).
- **מדת חסידות** :: פודין בזמן הזה **בשויו** כדרך שפודין
  בפני הבית; **והורו הגאונים** :: הרוצה לפדות שוה מנה
  **בפרוטה** — לכתחילה פודה: "**לא יהיה זה חמור מן
  הקדש**" — **ומשליך הפרוטה לים הגדול**.
- מחלל מעשר שוה מנה **על שוה פרוטה** מפירות אחרות ::
  **מחולל** — **ושורף את הפירות** שחלל עליהם, שלא יהיו
  תקלה לאחרים (כפדיון נטע רבעי בזמן הזה).
- **בירושלים בזמן הזה** :: אין אוכלין, אין פודין, אין
  מחללין ואין מוכרין; **ואם נכנס** — אין מוציאין אותו,
  **ומניחין עד שירקב**; ואם הוציאו :: כן. *לפיכך אין
  מפרישין מעשר שני בירושלים בזמן הזה.*

* ו. ⟐ סדר הבירור

1. איזו שנה? → א'-ב' ד'-ה': מ"ש; ג'-ו': מ"ע.
2. איזה ר"ה? → תבואה/קטניות/ירק: א' בתשרי; אילן: ט"ו בשבט.
3. מתי נגמר? → לפי **עונת המעשרות** (והירק — לקיטתו).
4. חרוב? → צלמונה: להבא; שאר: כאילן.
5. בזמן הזה? → פדיון בשוה (ואפילו פרוטה); בירושלים —
   מניחין עד שירקב.
6. ותמיד: אין מוכרין ואין מחליפין — ממון גבוה הוא.
