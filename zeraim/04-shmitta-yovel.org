#+TITLE: שמיטה ויובל — הכללים, מחלוקת זמננו, וסדרי הספירה
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות (מחוץ לשו"ע): ערוך השלחן העתיד זרעים סי' ט"ו (כלליות
שמיטה, י' סעיפים) וסי' ל' (כלליות יובל, ט"ו סעיפים) — נבדקו
מהטקסט; רמב"ם הל' שמיטה ויובל המצוטט בתוכו; ולמצוות הארץ
כולן — [[file:../yoreh-deah/08-mitzvos-haaretz.org][יו"ד 08]].

* א. ‡ היסוד — וכמה גדול עונשה

- מ"ע מן התורה בא"י :: להשמיט מעבודת הארץ אחת לשבע —
  "והשביעית **תשמטנה ונטשתה**" (משפטים); ובסיני נאמרה
  בכלליותיה ובפרטיותיה (בהר).
‡ *תורת כהנים* :: "אני אמרתי לכם שתהא זורעים שש ומשמטין
לי אחת, **בשביל שתדעו שהארץ שלי היא** — ואתם לא עשיתם כן:
**עמדו וגלו ממנה, והיא תשמט מאליה** כל שמיטין שהיא חייבת
לי."
- "על עון השמיטה — **גלות** בא לעולם" (אבות פ"ה); ושמירת
  שביעית מביאה ברכה — "וצויתי את ברכתי לכם."

* ב. ‡ מתי נתחייבו — י"ד שנה

אחר י"ד שנה מכניסתן (כיבשו **וחילקו**) — כדת"כ: מ"שדך"
שיהא כל אחד מכיר שדהו. ומנין השנים :: אחר י"ד — חלה וערלה
וחדש תיכף; **בשנה כ"א עשו שמיטה; בס"ד עשו יובל**.
⟐ *וזהו החלוק מתרומות* (שם נ' ס"א) — שם נתחייבו **תיכף**,
משום דשם כתיב "ראשית דגנך" ולא "שדך".

* ג. ‡ שמיטה בזמן הזה — דאורייתא או דרבנן?

** המחלוקת
- **רבי** (ירושלמי דמאי; גיטין ל"ו) :: שמיטה בזמן הזה —
  **מדבריהם**; שתי שמיטין כתיבי — קרקע וכספים, דוקא כשיובל
  נוהג.
- **רבי יוסי** :: שמיטת קרקע — דבר תורה כשהשמיטה נוהגת
  בארץ; **שמיטת כספים** — מדבריהם.
- ***והרמב"ם פסק דאורייתא*** :: ערו"ה העתיד מוכיח מהל' שמיטה
  ד:כ"ה ("אין שביעית נוהגת אלא בא"י... **בין בפני הבית בין
  שלא בפני הבית**") שלא כתב כדרכו "ובזמן הזה דרבנן", ומס'
  המצות עשין קל"ה.

** והראיות
- ערכין ל"ב :: "מנו יובלות — לקדש שמיטין; ויובל אינו נוהג
  **ושמיטה נוהגת**."
- ר"ת (תוס' ערכין) :: האי דאורייתא — אך דאתיא כרבנן ור"י;
  ותוס' דחו.
‡ *מסקנת הערוך העתיד* :: הלכה כרבים — **וכפסק הרמב"ם**;
ורש"י עצמו בסנהדרין כתב דבטלה קדושת הארץ — והערוך דחי
לפי הרמב"ם ⚠ (וזו מחלוקת ראשונים גדולה — לפוסקים בשאלות
מעשיות).

* ד. ‡ שמיטה בלא יובל, ויובל בלא שמיטה

ת"כ :: ר"י :: שניהם תלויים זה בזה לפי דרשות "והיו לך";
וחכ"א :: "**שביעית נוהגת אף שאין היובל נוהג; והיובל אינו
נוהג אא"כ יש עמו שביעית**" — *והלכה כחכמים* (ורש"י בפירוש
התורה כר"י, "אבל לא חשש בפירושו לכתוב לפי ההלכה" — ערו"ה).
⟐ *ואיך יובל בלא שמיטה?* — כגון שגלו וחזרו לפני יובל
ולא נהגו שמיטין.

* ה. יובל — על מה הוא תולה

"במצוות יובל תלוי הרבה עניינים" (ערו"ה ל' ס"א) :: חזרת
קרקעות; מקדיש שדה אחוזה/שדה מכר; ערי חומה וחצרים; שדה
חרמים; **עבד עברי ואמה העבריה**; גר תושב. והרמב"ם חילקן
בג' מקומות (שמיטה, ערכין, עבדים).

* ו. ‡ ספירת שמיטין ויובלות

- "**מסורין לב"ד הגדול בלבד**" (רמב"ם ריש פ"י) — דקדרשינן
  "**וספרת לך**" — בב"ד.
- הספירה בברכה :: "אשר קדשנו במצותיו וצונו **על ספירת
  השמיטה** — היום שנה ראשונה לשמיטה..." ובשמינית :: "שמנה
  שנים שהם שבוע אחד **ושנה אחת ליובל**" — עד שנת כ"א:
  "שלשה שבועות."
- **בשנת היובל עצמה — אין ספירה, אלא קידוש ותקיעה**; וביובל
  השני — מתחיל מחדש.
- ⟐ *ביום ולא בלילה?* — נ"ל מדסמכה תורה ספירה לתקיעה
  (ותקיעה ביום); "ולכשיבא משיח צדקנו במהרה בימינו —
  **יתברר הדבר**" (ערו"ה).

* ז. ‡ לשון "יובל"

- רש"י :: ע"ש **תקיעת השופר** — של איל, "יובלא" בלשון
  ערבי (וכן אונקלוס).
- **הרמב"ן** :: ע"ש **הדרור** — שכל אחד שב למשפחתו, והוא
  לשון **הובלה** ("יובל שי לה'", "על יובל ישלח שרשיו...
  יבלי מים") — "תהיה הבאה לכולכם: זה יבא אל משפחתו וזה
  תבא אליו אחוזתו."
⟐ *והערת הערוך*: ודאי דלא משום לשון ערבי בלבד נתפסה
התורה לשון — ונראה כרמב"ן.

* ט. ‡ פרטי איסורי השמיטה (ערו"ה העתיד ט"ז)

** גדרי המקום
- אילן שנטעו **בתוך הבית** :: ירושלמי מסתפק ("ושבתה
  **הארץ**" נגד "שדך וכרמך"); *ומסקנת הערוך* :: פטור —
  מדבעינן **עציץ נקוב** (גיטין ז).
- **כרם של הקדש** :: חייב בשביעית ("שבת לה'" — דבר שהוא
  לה'); וירושלמי :: הגזבר **מחליפו ביד אחר** — *והרמב"ם
  לא הביא דין זה, ולכן שדות הקדש אסורין כשדות הדיוט.*

** עכו"ם וקרקע בשביעית
- עכו"ם שקנה קרקע וזרעה :: **פירותיה מותרים** — "שלא
  גזרו על הספיחין אלא מפני **עוברי עבירה**, והעכו"ם
  אינן מצווין" (רמב"ם הל' שמיטה פ"ד ה"כה).
- ‡ *וחידוש הערוך* :: ישראל שקנה **שדה זרועה מעכו"ם
  בשביעית** — נוהג בה דין שביעית ("שעת קצירה היא של
  ישראל"); ודוחה את ראיית מעשה אלכסנדר מוקדן, ומביא
  **חוכרין נירין** ו**מחזיקין ידי עכו"ם** — "*ואם נאמר
  שמותר לקנות מהם שדות זרועות בשביעית ולקוצרם — אין
  לך החזקה גדולה מזו*... **נלע"ד לאיסור**."

** שלש ארצות לשביעית (משנה שביעית ו, א')
| ארץ (מי החזיקו)      | גבול              | דין                      |
|------------------------+--------------------+---------------------------|
| עולי **בבל**          | א"י **עד כזיב**    | **לא נאכל ולא נעבד**     |
| עולי **מצרים**        | מכזיב עד הנהר ואמנה | **נאכל ולא נעבד**        |
| ומשם ולפנים           |                    | **נאכל ונעבד**           |
- והרמב"ם בפירושו :: "לא נאכל" — אם עברו וזרעו בשביעית;
  ובחיבורו :: ד**ספיחין** קאי — ונ"ל דלדינא **כל
  הפירושים אמת** (ערו"ה).
- **סוריא** :: אין שביעית מן התורה — **וגזרו עליה עבודה**
  "כדי שלא יניחו א"י וישתקעו שם"; **אמון מואב מצרים
  ובבל** :: אין שביעית כלל — מותר לזרוע לכתחילה.

* י. ⟐ סדר הבירור

1. א"י בזמן הזה? → הרמב"ם: דאורייתא; ויש חולקין — **לפוסקים**
   במעשי ⚠.
2. שנת השמיטה? → זריעה וקצירה אסורין; ופירות שביעית —
   קדושין לאכילה (בהרחבה — לקובץ הבא ⚠).
3. ספירה? → ב"ד הגדול, בברכה, וביובל — קידוש ותקיעה בלבד.
4. ותמיד: הארץ של ה' — והשמיטה מוכיחה זאת.
