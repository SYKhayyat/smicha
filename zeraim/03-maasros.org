מקורות (מחוץ לשו"ע): משנה מעשרות א' א' עם הברטנורא, רש
משאנץ, ופירוש הרמב"ם (נבדקו מהטקסט); רמב"ם הל' מעשרות פ"א
(נבדק מהטקסט); ולסדר השנים — [[file:02-terumos.org][קובץ 02]];
ולמעשר עני — [[file:01-matnos-aniyim.org][קובץ 01]].

* א. ‡ הכלל — חמשת התנאים (משנה מעשרות א' א')

"**כל שהוא אוכל, ונשמר, וגדוליו מן הארץ** — חייב במעשרות."
ובמה דברים אמורים — כש**תחלתו אוכל וסופו אוכל**; ואפילו
שמרו להוסיף אוכל — אינו חייב עד שיעשה אוכל.

** הפטורים (בשלשת הפרשנים)
| תנאי      | הפטור                          |
|------------+---------------------------------|
| אוכל      | **סטיס וקוצה** (רמב"ם: הכופר והאסוס) — נאכלים רק ע"ה |
| נשמר      | **ההפקר** — אין לו בעלים       |
| גדוליו מן הארץ | **כמהין ופטריות** — אינן נזרעות |

** הדרשות (ברטנורא, ובירושלמי דרש רש)
"עשר תעשר את כל **תבואת** זרעך" — דומיא דתבואה שהוא אוכל;
"**זרעך**" — המיוחד לך (פרט להפקר); זרעך — דבר שזורעין
ומצמיח (פרט לכמהין ופטריות). ורש :: מ"ובא הלוי... **אין
לו**" — הפקר; ולקט שכחה ופאה פטורין מטעם זה.

* ב. ‡ מה חייב מן התורה — ומה מדבריהם

‡ רש משאנץ, מהירושלמי :: "מדאורייתא לא מחייבי אלא
**דגן תירוש ויצהר**" — וירקות **מדבריהן** ("שאין להן
אסמכתא מן הפסוק"); ומביא ראיות :: חרובין — דרבנן (ר"ה
טו:), צלף — דרבנן (ברכות לו:), תבלין — דרבנן (פסחים מד:),
ופירות אילן — דרבנן (נדרים נה:).
⟐ *וזהו ההיפוך המעניין מפאה*: שם — ר"ת לחומרא על אילנות
והרמב"ם להקל; כאן — הרמב"ם עצמו בפירוש המשנה דן בחיוב
הפירות לפי "**מזרע הארץ מפרי העץ**" עד שיעשה פרי.

* ג. זמן החיוב

- **תחילתו אוכל וסופו אוכל** (ירקות) :: חייב בין קטן בין
  גדול — "בירק אחר לקיטתו עישורו" (רש).
- **תחילתו אינו אוכל** (פירות) :: עד שיעשה אוכל; **התאנים
  משיבחילו** — ופירש הרמב"ם :: משיתחילו להתבשל — "וזמן זה
  הבשול הוא שמלקטין את התאנה מן האילן ומניחין **כ"ד שעות**
  ותהיה ראויה לאכילה."

* ד. ‡ מעשר ראשון (רמב"ם הל' מעשרות פ"א)

- אחר תרומה גדולה :: אחד מעשרה מן הנשאר — **ללוים**, זכרים
  ונקבות.
- ⟐ "**מעשר ראשון חולין לכל דבר**" — מ"גורן מן היקב"; אין
  בו קדושה כלל: מותר באכילה לישראל ובטומאה.
- *בת לוי* שנשבית או נבעלה בעילת זנות :: נותנין לה ואוכלת.
- **לוים וכהנים** מפרישין ממעשרם תרומת מעשר; וכהנים — שאר
  תרומות ומעשרות לעצמן ("כן תרימו **גם אתם**" — מפי
  השמועה).
- **אין מוציאין מיד הכהן** — וכן כל מתנות כהונה.
- ‡ ***וקנס עזרא*** :: שלא יתנו ללוים מעשר ראשון אלא
  **לכהנים** — לפי שלא עלו עמו.

* ה. טבל

- האוכל פירותיו טבלין — ולוי שאכל המעשר בטבלו :: **חייבין
  מיתה לשמים** — אבל **אין משלמין** ("אין לך בהן כלום עד
  שירימון").
- **בחוץ לארץ** :: מותר לאכול ולהלך **תחלה** — ואח"כ מפריש
  תרומות ומעשרות.

* ו. מעשר שני ומעשר עני — הסדר השנתי

לפי השנים (ערו"ה העתיד נ' ס"ג, ועי'
[[file:02-terumos.org][קובץ 02]]) :: שנים א'-ב' וד'-ה' ::
**מעשר שני** — נאכל בירושלים בקדושה; שנים ג'-ו' :: **מעשר
עני** — לעניים. ופרטי מעשר שני (ביאור, פדיון, נטע רבעי) —
לקובץ הבא ⚠.

* ז. ⟐ סדר הבירור

1. חייב? → חמשת התנאים; והפטורי דרך (הפקר, כמהין, סטיס).
2. מן התורה? → דגן תירוש ויצהר בלבד; השאר — דרבנן.
3. מתי? → ירקות משלקיטה; פירות עד שיעשו אוכל; תאנים —
   משיבחילו.
4. הסדר? → ת"ג → מ"ר (חולין!) → ת"מ → מ"ש/מ"ע.
5. טבל? → מיתה לשמים ואין תשלום; בחו"ל — אוכל תחלה.
