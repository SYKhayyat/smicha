#+TITLE: חושן משפט — ירושות, צוואות, סדר נחלות, והבכור
#+LANGUAGE: he
#+STARTUP: overview
#+OPTIONS: toc:3 num:nil

מקורות: שו"ע ורמ"א חו"מ סי' רע"ו (סדר נחלות), רע"ז—רע"ח (הבכור),
ר"נ—רנ"ו (שכיב מרע ומתנות), רפ"א—רפ"ב (אין להוריש מי שאינו ראוי);
בבא בתרא י"ד—קנ"ו; ובאחרונים — נתיבות וקצות ⚠; למעשה בצוואות בנות
זמננו — ספרי הפוסקים ובתי הדין ⚠.

*אזהרה:* ענין זה כולו נלמד כאן כ*מפה*. צוואה אחת טעות גורמת תקנות
וממונות ומחלוקות ירושה לדורות — אין עושים ואין פוסקים בה מן הקבצים,
אלא מול פוסק ובית דין.

* א. ‡ סדר הנחלות (סי' רע"ו)

** הסולם
1. *בן* — יורש הכל.
2. אין בן :: *זרעו* — בנים ובנות, עד סוף כל הדורות.
3. אין זרע לבן :: *בת*, ואח"כ זרעה עד סוף כל הדורות.
4. אין :: *אחי המת*, ואח"כ זרעם; ואח"כ *אחותו* וזרעה.
5. ומשם ולמעלה :: אחי אביו ואחיותיו, אחי סבו ואחיותיו — "נחלה
   ממשמשת ובאה" עד ראובן.

** ‡ הכללים המכריעים בתוך הסולם
- *זרע עומד במקום בנו* — אפילו בת הבן, ואפילו בת בת בת הבן, *קודמת
  לבת* עצמה (רע"ו ס"ב). ⟐ בת־בן נגד בת: בת הבן יורשת הכל.
- כשמתו *שני בנים בחיי אביהם* :: חולקים כאילו חיים — בני זה נגד בני
  זה, וכן בני אחים ובני אחי אב כל הדורות (רע"ו ס"ג).
- *משפחת האם אינה משפחה* :: האם אינה יורשת את בנה ולא את בתה, ואחין
  מאם אינם יורשים זה את זה. אבל *הבן יורש את אמו* והבת את אמה (ר"ל
  ס"ד).
- *שתוקי* :: אין לו יורשין מן האב — הרי הוא כגר, ונכסיו הפקר (רמ"א).
- ירושת האם :: בנה ובתה שוים — אלא שבן וזרעו קודמין לבת (רע"ו ס"ד).
- הבן שמת בחיי אמו :: אינו מנחיל ליורשיו מן האב בנכסי אמו — חוזרת
  למשפחת אביה; אבל אם חי אחריה אפילו שעה אחת — ירש ומנחיל (רע"ו ס"ה;
  *והעובר אינו יורש את אמו* — רמ"א).
- ממזר וכל פסולי חיתון :: יורשים ככשרים; בן שפחה או עכו"ם — אינו
  יורש כלל (רע"ו ס"ו).
- יורשים אינם נוטלין דברים שאין בהם ממש וטובת הנאה בעלמא (רמ"א).

* ב. ‡ הבכור (סי' רע"ז—רע"ח)

** החשבון
הניח ה' בנים ואחד בכור :: הבכור נוטל *שליש*, וכל פשוט *שתות*. הניח
ט' :: הבכור חמישות, וכל פשוט עשירית. שני חלקי הבכור נטולים כאחד
(רע"ז ס"א—ב).

** ‡ במה הבכור נוטל פי שנים — ובמה לא
- דוקא בנכסי *אב* — לא בנכסי אם (רע"ח ס"א).
- דוקא ב*מוחזק* לאב — לא ב*ראוי* (מלוה, ירושה שבאה לאב אחר מיתתו)
  (רע"ח ס"ג).
- *אינו נוטל במלוה* אף בשטר; במשכון — נוטל; וקרקע משועבדת לאחרים =
  מוחזק (רע"ח ס"ז ורמ"א).
- *אינו נוטל בשבח* שבא לאחר מיתה אם נשתנו הנכסים; שבח מחמת עצמן
  (אילן גדל, ארץ עלתה שרטון) — נוטל; ומי שמיחה — כדיני המחאה
  (רע"ח ס"ו ורמ"א).
- מתנות של מוכרי אביו שנשחטו קודם מיתתו — נוטל פי שנים (רע"ח ס"ה).

** מי הוא בכור לנחלה
- בכור ל*אב* — אין משגיחין על האם (רע"ז ס"ח).
- נולד אחר מיתת אביו :: אינו נוטל פי שנים; יצאה פדחתו בחיי האב — נוטל
  (רע"ז ס"ג).
- קטן בן יום אחד ממעט בכורה; העובר לא (רע"ז ס"ה).
- בכור ממזר נוטל פי שנים (רע"ז ס"י).
- ספק בכור :: אינו נוטל פי שנים; וכשהוכרו ולבסוף נתערבו — כותבין
  הרשאה זה לזה (רע"ז ס"יא ורמ"א).
- נאמנות :: *חיה, ואמו שבעת ימי הלידה, ואביו לעולם* (רע"ז ס"יב).

* ג. ‡ מתנת שכיב מרע — גדרי הצוואה (סי' ר"נ)

** היסודות
1. *אין צריך קנין* — "דברי שכיב מרע ככתובים וכמסורים דמי" (ס"א).
2. *כל נכסיו ולא שייר כלום* :: קונה בלא קנין; ושייר כלום — אפילו
   כל שהוא — דינו כבריא: **צריך קנין** (ס"ד).
3. *עמד ונתרפא לגמרי* :: מתנת כולה בטלה מאליה, אף אם התנה שלא
   יחזור (ס"ב). עמד ונשען על מקלו בשוק :: בטל; בתוך ביתו :: מתנתו
   קיימת; בין חולי לחולי :: אומדין ע"פ רופאים (ס"ב).
4. *המפליג והיוצא בשיירא* :: דינו כמצוה מחמת מיתה — קיימת אף אם
   ניצל, ואפילו קנו מידו במקצת (ס"י).
5. מתנה במקצת סתם :: צריך קנין ואם עמד חוזר; ואם ניכר שנותן
   *מחמת מיתה* — אף במקצת קונה לכשימות (ס"ט).
6. חילק לשנים ולא הפסיק בין אחד לחבירו :: הכל כולה וקנו בלא קנין;
   הפסיק :: הראשונים כבמקצת (ס"יג).
7. *צוה לכתוב שטר עם הנתינה* :: חוששין שמא לא גמר להקנות אלא
   בשטר — ואין שטר לאחר מיתה; אא"כ ייפה כחו (ס"כ).

** ‡ צוואה כתובה — לשון צוואה ולשון מתנה
- שטר הכתוב בלשון צוואה ("צוה אל ביתו") — אינו אלא לראיה; הגיע ליד
  המקבל מחיים — קנה (ס"כ).
- ובמקום *שנהגו שכולן מקנין בצוואה בעלמא* ואין מכוונין להקנות בשטר —
  א"צ יפוי כח (רמ"א מהריב"ש). ⟐ וזה יסוד הצוואות הנהוגות.
- צוואת שכיב מרע שלא נכתב בה "מיושב בדעתו" — אין חוששין; המנהג
  לכתבו לשופרא דשטרי (רמ"א מהריטב"א).
- *יזהרו שלא לכתוב בצוואת ש"מ "במתנת בריא" או "מהיום"* אם לא צוה
  כך — שאז צריך קנין, ואין אומרין טעות סופר (רמ"א).

* ד. ‡ אין להוריש מי שאינו ראוי, ולא לעקור הירושה (סי' רפ"א—רפ"ב)

** הכלל
"אין אדם יכול להוריש מי שאינו ראוי ליורש, ולא לעקור הירושה מהיורש"
— בין שצוה בריא בין שכיב מרע, בין על פה בין בכתב:
- "פלוני בכורי לא יטול פי שנים", "בתי תירשני במקום שיש לו בן" ::
  לא אמר כלום.
- *ואם היה לו יורשים רבים* (בנים רבים, אחים, בנות) וריבה לאחד
  ומיעט לאחד :: דבריו קיימים (רפ"א ס"א).
- בפשוטים יכול לסלק ולהרבות; בבכור — לא, "לא יוכל לבכר את בן
  האהובה"; ואפילו במקום שנהגו שאין הבכור נוטל פי שנים — אין הולכין
  אחר המנהג (רפ"א ס"ד ורמ"א).
- בריא :: אינו יכול להוסיף ולא לגרוע (רפ"א ס"ה).
- ‡ *לשון מתנה* :: דבריו קיימים — אף שהשייר ליורשים כלום, אף למי
  שאינו ראוי ליורשו (רפ"א ס"ז). והמכתוב "משום מתנה" בין בתחלה בין
  בסוף — קיים אף שהזכיר לשון ירושה.
- *לשון יחזיק בנכסים, יחלוקו* :: לשון מתנה (רפ"א).

** ‡ צוואה לבת — חצי זכר
הכותב לבתו שתקח כחצי חלק זכר :: דינו *כירושה בעלמא* — בעל חוב
וכתובה קודמין, ועשור לבנים, וכל ימי חיי האב רשאי למכר (רמ"א).
ומה שנוהגין לכתוב לבת שטר חוב בתנאי — עיקרו החוב, וצריך לקיים
תנאו או לשלם (רמ"א).

** מדת חסידות (רפ"ב)
כל הנותן נכסיו לאחרים והניח היורשים — *אין רוח חכמים נוחה הימנו*;
וזכו האחרים במה שנתן. ומדת חסידות שלא להעיד בצואה שמעבירין בה
הירושה — אפילו מבן שאינו נוהג כשורה לאחיו החכם. והרמ"א: מי שצוה
לעשות בנכסיו הטוב שאפשר — *יתנהו ליורשיו, כי אין טוב מזה*.

* ה. ⟐ צוואות בנות זמננו — דרך הלימוד

*כאן אין פסקים, אלא מפה:* הצוואה האזרחית אינה עוברת כלשונה —
לשון ירושה לסלק יורשים בטלה (רפ"א), ולשון מתנה צריך קנין כדיני
מתנות (עי' [[file:02-kinyanim.org][חו"מ 02]]), והבכור אינו נפגע אפילו
במנהג (רפ"א ס"ד). ומה שנוהגים בשטרי "חצי זכר" ובתנאי הצוואות — יסודו
ברמ"א כאן, ופרטיו בספרי הפוסקים ובבתי הדין ⚠. *וכל עריכת צוואה — עם
פוסק ובית דין, לפני החתימה ולא אחריה.*

* ו. ⟐ סדר הבירור

1. מת? :: קבע מי היורשים ע"פ סעיף א — ואח"כ
   בדוק בכור (רע"ז—רע"ח).
2. בכור :: מוחזק נגד ראוי? מלוה? שבח? מחאה?
3. יש צוואה/מתנה? :: לשון ירושה או לשון מתנה? כל נכסים או מקצת?
   שיור כלום? קנין? עמד ונתרפא?
4. שכיב מרע או בריא? מפליג/שיירא = מצוה מחמת מיתה?
5. צוואה כתובה :: לשון צוואה (לראיה) או מתנה? יפוי כח? מנהג
   המדינות?
6. בת :: חצי זכר — דינו כירושה; חובות קודמין.
7. ובכל אלה — *בית דין ופוסק*, ולא מן המפה הזאת.
