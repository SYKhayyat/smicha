קובץ זה הוא יסוד לכל איסור והיתר, ולא לבשר בחלב בלבד.
מקורות: חולין ק"ח—קי"ב; רמב"ם מאכלות אסורות פ"ט, פט"ו; טור וב"י ושו"ע יו"ד
סי' ס"ח—ע', צ"א—צ"ו, ק"ה; ש"ך וט"ז שם.

* היסוד הכללי — אין טעם עובר בלא כח מפעיל

שני דברים הנוגעים זה בזה בצונן — אין אחד אוסר את חברו כלל, שאין הטעם עובר
מאליו. ולא נאסר אלא ע"י אחד מחמשה כוחות:

| הכח    | מהותו              | שיעורו                  | עומק החדירה           |
|--------+--------------------+-------------------------+-----------------------|
| רותח   | חום לח             | יד סולדת בו             | לפי הכלי — עי' קובץ 03 |
| צלי    | חום יבש            | חום האש                 | כדי קליפה / כולו      |
| כבוש   | שהייה בנוזל        | מעת לעת                 | כולו                  |
| מליח   | שריפת המלח         | שאינו נאכל מחמת מלחו    | כדי קליפה             |
| חריף   | חריפות מוליכה      | דבר חריף                | כדי קליפה / כולו      |

*הכלל שמאחורי כולם:* הטעם צריך שיהא לו במה לנוע. חום מרתיח ומפעפע, נוזל
מסיע, שומן מוליך, חריפות פותחת. יבש וקר — עומד במקומו.

* א. ‡ רותח — שיעור "יד סולדת בו"

** ההגדרה
"יד סולדת בו" — שהיד נכווית ונרתעת ממנו. ובגמרא (שבת מ' ע"ב) נחלקו בשיעורו,
ומסקנת הפוסקים שהוא כל שכריסו של תינוק נכוית בו.

** ‡ מחלוקת האחרונים בשיעור המעלות
- שיטה מקילה :: כארבעים ושתים עד ארבעים וחמש מעלות. ⚠
- שיטה מחמירה :: יש שהעלו שיעור גבוה יותר, עד למעלה מששים. ⚠
- למעשה :: בשל תורה מחמירים מן השיעור הנמוך — כל שהגיע לכארבעים וחמש
  יש לחוש; ובדרבנן ובדיעבד מקילים.

** ⟐ נפקא מינות
1. נוזל חם שלא הגיע ליד סולדת — אינו מבליע ואינו מפליט כלל.
2. לענין שבת — שיעור בישול (עי' [[file:../shabbos/07-bishul.org][שבת 07]]) הוא אותו שיעור, ויש
   שהחמירו שם יותר.

** קליפה ונטילה
- כדי קליפה :: עובי דק שעל פני השטח.
- כדי נטילה :: כעובי אצבע (כשיעור נטילת מקום). ⚠
- כולו :: כשיש רוטב, שומן, או שהיו שניהם רותחים.

* ב. ‡ צלי

** 1. האם חייבים על צלי בבשר בחלב

היסוד: הכתוב אמר "לא ת*בשל*". ונחלקו הראשונים אם צלייה בכלל בישול.

- ‡ שיטה א' :: "בישול" דוקא — במים או במשקה, כדרך בישול. והצולה בשר בחלב
  אינו חייב מן התורה, ואיסורו מדרבנן.
- ‡ שיטה ב' :: אף צלי בכלל, שכל תיקון האוכל באש קרוי בישול, ולא בא הכתוב
  אלא למעט צונן. ⚠
- ⟐ נפקא מינה :: ספק בצלי בשר בחלב — לשיטה א' ספק דרבנן ולקולא; לשיטה ב'
  ספק דאורייתא ולחומרא. וכן לענין שיעור הביטול.

** 2. עומק חדירת הטעם בצלי — היסוד המרכזי

בצלי אין הטעם מתפשט בכל החתיכה כמו בבישול, שאין נוזל שיסיענו. וכלל גדול:

#+begin_quote
*שומן וציר מוליכים; יבש אינו מוליך.*
#+end_quote

- אין רוטב ואין שומן :: הטעם נכנס *כדי קליפה* במקום המגע בלבד.
- יש שומן או ציר :: השומן מפעפע ומוליך את הטעם *בכל החתיכה*.
- שניהם רותחים ממש :: אוסר כולו.
- ‡ מחלוקת :: יש מן הראשונים שסוברים שאף בלא שומן פעפוע הולך בכולו,
  מפני שהאש מבליעה בכל. ⚠

** 3. צלי בשיפוד ובתנור
- שני מיני בשר בשיפוד אחד — הטעם עובר דרך השיפוד, שהמתכת מוליכה.
- בתנור אחד — אם שניהם מגולים ויש הבל, יש חשש שהריח והזיעה מעבירים טעם.
  ועי' להלן דין *ריח* וזיעה.

** 4. ‡ ריחא מילתא — האם ריח אוסר

פסחים ע"ו ע"ב: "ריחא מילתא היא" או "ריחא לאו מילתא היא".

- להלכה :: ריחא לאו מילתא — בדיעבד אינו אוסר.
- לכתחילה :: אין לצלות בשר וחלב בתנור אחד.
- להלכה למעשה ::
  - אשכנזים :: הרמ"א מחמיר לכתחילה בתנור סגור; ובתנור פתוח מקילים.
  - ספרדים :: מרן מקיל טפי; והגר"ע יוסף האריך להקל בתנורי זמננו כשאין
    שניהם מגולים, ובמכוסה מותר אף לכתחילה. ⚠

** 5. ‡ זיעה
זיעה של איסור העולה ונוגעת — דינה כאיסור עצמו כשהיא רותחת, ואינה כריח בעלמא.
זהו ההבדל היסודי: *ריח* — אין בו ממש; *זיעה* — יש בה ממשות של נוזל.
⟐ נפקא מינה: תנור שבישלו בו בשר ואח"כ חלב מגולה.

* ג. ‡ כבוש כמבושל

** 1. הדין ושיעורו
דבר ששהה בתוך נוזל *מעת לעת* — כ"ד שעות — הרי הוא כמבושל, והטעם עובר.

** 2. ‡ האם כבוש מדאורייתא
- שיטה א' :: מדאורייתא, ד"כבוש הרי הוא כמבושל" הלכה למשה מסיני היא, או
  שהוא בכלל בישול.
- שיטה ב' :: מדרבנן בלבד, ומדאורייתא אין הטעם עובר אלא בחום.
- ⟐ נפקא מינה :: ספק בכבוש; ושיעור הביטול — שישים או רוב; ובשבת, אם יש
  איסור כבישה.

** 3. פרטי הדין
1. *מכוסה* — צריך שיהא הדבר מכוסה בנוזל. ואם צף מקצתו — נחלקו האחרונים
   אם החלק הצף נאסר. ⚠
2. *הפסק בשהייה* — אם הוציאו קודם מעת לעת והחזירו: נחלקו אם מצטרפות
   השהיות. להלכה לחומרא בשל תורה. ⚠
3. *הנוזל* — מים, יין, ציר, חומץ, וכל משקה. אבל דבר יבש — אין בו כבישה כלל.
4. *מים צוננים* — לרוב הפוסקים אף מים צוננים כובשים.
5. *הכלי עצמו* — כלי ששהה בו איסור מעת לעת בצונן, בלע.

** 4. להלכה
שו"ע ורמ"א יו"ד סי' ק"ה ס"א. ⚠ מחמירים בכבוש כבבישול. ובדיעבד ובהפסד
מרובה יש מקום להקל, ובפרט לספרדים.

* ד. ‡ מליח כרותח

** 1. היסוד
מלח שורף ומפליט את הדם והלחלוחית, ולפיכך דבר מלוח דינו כרותח.

** 2. התנאי — "מליח שאינו נאכל מחמת מלחו"
לא כל מליחה, אלא דוקא כשהמלח רב עד שאין הדבר ראוי להיאכל מחמת מלחו.
וכל שראוי לאכילה — אין בו דין מליח כרותח כלל.

** 3. ‡ עומק ההבלעה
- דעת רוב הפוסקים :: מליח כרותח *כדי קליפה* בלבד, שאין כח המלח כחום גמור.
- ויש שהחמירו :: כרותח גמור לאסור כולו. ⚠
- להלכה :: שו"ע יו"ד סי' ק"ה ס"ט ⚠ — כדי קליפה.

** 4. חילוק בין מולח לנמלח
- ה*מולח* — הוא הפולט.
- ה*נמלח* עמו — הוא הבולע.
- וכשהמליחה בכלי מנוקב, הציר יוצא ואינו חוזר; ובכלי שאינו מנוקב, הציר
  נקווה וחוזר ובולע. ⟐ נפקא מינה גדולה במליחת בשר — עי' [[file:../issur-veheter/03-melichah.org][מליחה]].

* ה. ‡ דבר חריף

** 1. שני כוחות נפרדים בחריף — וזהו תרי דיני

1. *מוליך* :: החריפות מעבירה טעם אף בצונן ואף בכלי שני, שאין החריף צריך
   לחום כדי להפעפע.
2. *מחליא* :: "חורפיה מחליא ליה" — החריף *הופך טעם פגום לטעם משביח*.
   ולכן דבר חריף שנחתך בסכין שאינו בן יומו — שהבליעה בו פגומה — החריפות
   מחזירתה להיות משביחה, ואוסרת. ⚠

זהו יסוד גדול: בכל האיסורים "נותן טעם לפגם מותר", ובחריף נעקר הכלל.

** 2. מהו דבר חריף
בצל, שום, צנון, כרישה, לימון, פלפל חריף, חמוצים, מלח, ולדעת רבים אף
דברים חמוצים ביותר.

** 3. ‡ שיעור האיסור
- דעת רוב הראשונים :: חריף שנחתך בסכין — אוסר *כדי קליפה*.
- הרמ"א :: מחמיר במקצת מקרים לאסור את כולו, ובהפסד מרובה מקילים. ⚠
- ‡ יסוד המחלוקת :: האם החריפות רק *מוציאה* את הבלוע בסכין (וממילא רק
  כדי קליפה, שאין בסכין אלא כדי קליפה), או שהיא *מפעפעת בכל החתיכה*.

** 4. להלכה
שו"ע ורמ"א יו"ד סי' צ"ו.
- אשכנזים :: הרמ"א והש"ך מחמירים; בהפסד מרובה ובדיעבד מקילים. ובסכין
  נקי ואינו בן יומו — רבים מקילים בדיעבד.
- ספרדים :: מרן מקיל טפי. והגר"ע יוסף הרחיב להקל בסכין נקי, ובפרט
  בסכיני נירוסטה של זמננו שאין בהם בליעה מרובה כבסכיני הראשונים. ⚠

** 5. ⟐ נפקא מינות מרכזיות
1. חיתוך בצל או לימון בסכין בשרי — האם הבצל נעשה בשרי ואסור עם חלב.
   - אשכנזים: יש להחמיר (ובנקי ואינו בן יומו יש מקום להקל בדיעבד).
   - ספרדים: מקום רחב להקל.
2. סכין פרווה ששימש לבשר, וחתכו בו לימון לתוך תה חלבי.
3. ממחה חשמלי (בלנדר) שטחנו בו דבר חריף.
4. מלח שנפל לתוך תבשיל — אינו נחשב חריף לענין זה כשהוא מפוזר.
